# Storyboard / Sequence Skill

## Purpose

This Skill turns approved Frame Scripts and a visual thesis into full-sequence visual staging.

It does not finish typography, generate final images, or replace Editorial Design.

## Inputs

- Script Aligned Creative Script;
- every Frame Script and Written Visual Requirement;
- exact copy and evidence;
- selected visual thesis;
- target surface and sequence behavior;
- Art Director assignment.

## Method

### 1. Map the sequence function

Record:

- opening promise;
- setup;
- progression;
- evidence or mechanism reveal;
- escalation or contrast;
- payoff;
- aftertaste or CTA.

Use only stages actually needed by the project.

### 2. Stage every page or beat

For each frame define:

```markdown
Page:
Editorial job:
Frame Script source:
Dominant visible event / information state:
Primary subject / evidence:
Copy mass and reading priority:
Approximate image / type balance:
Continuity from prior page:
Difference from adjacent pages:
Transition to next page:
Unresolved design question:
```

The storyboard may use rough blocks and provisional masses. It must not pretend rough staging is final page design.

### 3. Test continuity

When the project depends on a shared object, process, character, interface, system, or evidence chain, verify that the audience can follow it across pages.

Continuity does not require identical composition. It requires stable identity and intelligible change.

### 4. Test differentiation

Check whether adjacent pages differ in:

- visible event;
- information state;
- scale;
- density;
- image / type authority;
- emotional energy;
- evidence role;
- viewpoint or spatial relationship.

Difference must serve editorial progression, not random variety.

### 5. Test rhythm

View all pages simultaneously. Diagnose:

- repeated templates;
- equal loudness;
- premature climax;
- long stretches of the same density;
- missing pause or release;
- weak cover / payoff relation;
- evidence arriving too early or too late.

### 6. Select representative page classes

Identify the smallest set that requires high-fidelity proof, such as:

- cover / world page;
- body explanation page;
- evidence or process page;
- payoff page.

Do not assume two polished pages prove all classes.

## Output

```markdown
# Storyboard / Sequence Return

Project:
Sequence function:
Full-page storyboard:
Page-by-page staging:
Copy-mass map:
Continuity findings:
Differentiation findings:
Density / scale / energy curve:
Representative page classes:
Pages needing Image Direction:
Pages needing special Typography or evidence treatment:
Risks and unresolved questions:
Self-check:
Recommended Art Director disposition:
```

## Self-check

- Is every approved page present?
- Can the sequence be understood at contact-sheet scale?
- Does every page have a distinct reason to look different?
- Are shared identities and transformations trackable?
- Does exact copy have credible provisional space?
- Are high-fidelity proof needs correctly selected?
- Has final layout remained open to Editorial Design?

## Failure routing

- page job or sequence logic weak → Editorial Content Architecture;
- visible event unclear → Editorial Frame Script;
- visual thesis cannot sustain sequence → Visual Concept;
- copy mass impossible → Editorial Design / Typography, and Editorial if copy itself is excessive;
- image continuity challenge → Image Direction.
