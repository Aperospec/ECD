# Typography Skill

## Required method

Read and execute `METHOD.md` in this directory. The method is mandatory; this wrapper registers the capability and defines its V3 reporting boundary.

## Role boundary

Typography owns:

- type-role systems;
- typeface and fallback reasoning;
- dominant headline shape;
- Chinese and mixed-script line behavior;
- spacing, leading, alignment, and optical correction;
- image–type interaction;
- target-width and exported proofs;
- production-reproducible specifications.

It collaborates with `ecd-editorial-design` and reports to `ecd-art-director`.

It does not:

- rewrite approved copy without Editorial authority;
- treat font selection as the whole discipline;
- solve excessive copy by unreadable shrinking;
- approve its own work;
- release directly to Producer or ECD.

## Additional V3.1 requirements

- Exact copy must be used for critical proofs.
- A typographic system is judged perceptually at target size, not by ratios alone.
- Chinese punctuation, line starts / endings, script transitions, numerals, and fallback glyphs require explicit inspection.
- Proof must include actual rendered or exported output, not only stated settings.
- Do not claim a separate typographer or agent; report the distinct registered method pass accurately.

## Specialist Return

Use the return format in `METHOD.md` and add:

```markdown
Registered Skill: ecd-typography
Skill version: 3.1-alpha
Method file: METHOD.md
Authoritative exact copy:
Editorial Design reference:
Artifact / specification produced:
Actual proofs inspected:
Open Editorial or Production issue:

```

The return is not Department Cleared until Art Director reviews the actual proofs.
