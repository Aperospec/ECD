# Finished Art Skill

## Purpose

Finished Art turns Department Cleared design into precise, reproducible final layouts.

It is not a new design round. It must preserve approved hierarchy, page class, image–type relationship, crop, exact copy, evidence, and sequence.

## Inputs

- Department Cleared visual package;
- approved representative design comps;
- exact page geometry and safe areas;
- final image assets and provenance;
- Typography specification;
- exact copy;
- masks, overlap, layer order, grid, crop, and variant rules;
- Production Director assignment.

## Method

### 1. Build the implementation map

For every page record:

- target dimensions;
- approved design reference;
- image assets;
- copy blocks and typesetting reference;
- evidence and source elements;
- grid and alignment axes;
- crop and safe areas;
- masks and depth planes;
- reusable components;
- variant behavior;
- allowed tolerances;
- upstream return conditions.

### 2. Assemble editable layers

Keep imagery, type, masks, evidence, and graphics separately controllable where the toolchain permits.

### 3. Match approved design

Compare:

- dominant mass and hierarchy;
- center of gravity;
- image–type relationship;
- scale and density;
- grid and spacing;
- crop and edge tension;
- local contrast;
- overlap and occlusion;
- sequence grammar.

### 4. Resolve production craft

Refine:

- masks and edges;
- contact and depth;
- local tonal correction;
- perspective consistency;
- repeated component behavior;
- optical alignment;
- evidence legibility;
- variant-specific balance.

Do not use emergency cards, boxes, or smaller copy to conceal a design conflict.

### 5. Build variants intentionally

Adapt from the approved system rather than blind-cropping a master. Recheck hierarchy, copy fit, protected zones, and crop for every variant.

### 6. Export proofs and finals

Create:

- final-resolution files;
- contact sheet;
- actual-width preview;
- thumbnail preview;
- safe-area / overlay preview;
- variant comparison.

## Self-check

- Does final assembly match the approved design?
- Are exact copy and evidence still readable?
- Are image and type still one composition?
- Are masks, edges, depth, crop, and local contrast credible?
- Does every variant preserve the communication?
- Can Technical QA open and verify all files?

## Failure routing

- final image defect → Image Production;
- text implementation defect → Production Typesetting;
- approved design cannot survive target variant → Visual Department through Producer;
- technical file issue → Technical QA;
- content or claim mismatch → Editorial / Development through Producer.
