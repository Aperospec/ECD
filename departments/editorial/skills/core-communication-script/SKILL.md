# Core Communication Script Skill

Constitution clause: `SEM-048`.

## Purpose

The Core Communication Script defines what the audience is actually taken through from opening to payoff.

It exists after Creative Treatment Greenlight and before dependent page adaptation. Its purpose is to let the ECD judge whether the underlying story, argument, explanation, demonstration, comparison, procedure, or thematic progression is compelling and coherent before the studio invests in page mapping, Frame Scripts, exact copy, and visual work.

It is not:

- another Treatment summary;
- a list of themes the studio plans to mention;
- a final page sequence;
- a Frame Script;
- exact page or publication copy;
- a Storyboard or visual treatment.

## Inputs

- Greenlit Creative Treatment and accepted Development decisions;
- audience, platform, intended use, and Deliverable Contract;
- Evidence Obligation and public claim ceiling;
- Concept Reframing Record or other source posture when applicable;
- active Editorial inputs and references;
- speaker, reality, and certainty boundaries;
- ECD feedback;
- Editorial Director assignment.

## Method

### 1. Select the communication form

Choose one or a deliberate mix:

- narrative;
- explanatory;
- demonstrative;
- comparative;
- procedural;
- evidentiary;
- thematic / associative;
- persuasive;
- speculative.

Do not force chronology merely because the work will have several pages.

### 2. Define audience movement

State:

- what the audience initially assumes, knows, or feels;
- what first earns attention;
- what question, tension, promise, or curiosity drives continuation;
- what must change in understanding or feeling;
- what should remain after the work ends.

### 3. Write the actual progression

Write the full communication progression in connected prose or clearly ordered beats.

The script must reveal the real content, not merely announce that the content will later be written.

As applicable, include:

- opening condition, image, claim, question, or situation;
- each consequential development;
- the relation between adjacent developments;
- evidence, demonstration, contrast, or example at the point it changes interpretation;
- decisive shift, discovery, reversal, synthesis, or realization;
- ending, payoff, consequence, invitation, or aftertaste.

Each beat must change the audience state or advance the governing relationship.

### 4. Preserve speaker and reality position

Record whether the script is:

- personal experience;
- source-based explanation;
- independent concept reframing;
- hypothetical example;
- fictional narration;
- concept visualization;
- speculation;
- demonstration;
- mixed, with boundaries clearly identified.

Do not use first-person factual certainty for events the ECD did not say occurred.

Do not add defensive disclosure when the script makes no claim requiring it.

### 5. Identify essential and adaptable content

Separate:

- essential beats whose removal would change the accepted communication;
- supporting examples that may be replaced;
- material that may be compressed or expanded;
- order that is fixed by causality or argument;
- order that remains open to page adaptation;
- facts, limitations, or source conditions that must survive.

### 6. Stress-test the script

Ask:

- Is the opening specific enough to earn attention?
- Does the middle actually progress, or merely restate the premise?
- Is there a meaningful change, discovery, explanation, comparison, or payoff?
- Is every major beat necessary?
- Does the ending earn its conclusion?
- Is the script more interesting and concrete than the Treatment summary?
- Could a nearby but easier story have replaced the accepted project?
- Does any example take over and replace the governing idea?
- Would changing this script invalidate multiple downstream artifacts?

### 7. Recommend gate mode

Apply `core/HIGH_LEVERAGE_DECISIONS.md` and recommend:

- Separate Core Script Alignment;
- Combined with Creative Script Alignment;
- Existing Aligned;
- Not Applicable.

The recommendation is based on downstream dependency and invalidation cost, not fixed page count.

## Prohibited output

The Core Communication Script must not include binding:

- page count or page numbering;
- page-to-beat mapping;
- Frame Scripts;
- exact page headlines or body copy;
- complete publication caption;
- palette, typography, layout, object placement, camera, lighting, image style, or image prompt.

A short phrase may be used inside the script only when it is inseparable from the communication idea; it does not become approved exact copy unless the later decision scope says so.

## Self-check

- Can the ECD judge the actual communication, not only the intention?
- Does the script have a real progression and payoff appropriate to its mode?
- Is it faithful to the Greenlit Treatment?
- Are speaker, reality, evidence, and source positions accurate without unnecessary explanation?
- Are essential and adaptable beats distinguishable?
- Has dependent page and visual work remained inactive when Separate Alignment is required?
- Is the recommended gate mode proportionate?

## Failure routing

- the project premise or angle is weak → Development through Producer;
- the script is an abstract synopsis → rewrite within Core Communication Script;
- the communication form is wrong → Core Communication Script / Editorial Director;
- evidence or source dependency changes the premise → Development Research / Claims Rights;
- the script contains page architecture → remove and defer to Content Architecture;
- the script contains visual design → remove and defer to Visual;
- the ECD rejects the progression → revise this artifact before dependent Editorial Adaptation.
