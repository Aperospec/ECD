# Copy Editing Skill

## Purpose

Copy Editing challenges and improves a completed draft. It is not a second drafting pass that merely polishes sentences.

It must inspect the actual draft against authoritative inputs and produce visible editorial changes or a reasoned no-change finding.

## Inputs

- Greenlit Treatment;
- Content Architecture and Frame Scripts;
- complete Copywriting Return;
- source / claim / rights conditions;
- audience and platform contract;
- Editorial Director assignment.

## Method

### 1. Reconstruct intended communication

State:

- core proposition;
- audience movement;
- speaker position;
- factual / conceptual status;
- role of each page and publication section.

### 2. Compare draft to authority

Check whether the draft:

- changed the project premise;
- overemphasized a side example;
- added unsupported capability or result claims;
- converted speculation into fact;
- converted a fictional or hypothetical scene into an apparent personal experience;
- introduced sales, tutorial, or promotional framing excluded by Treatment;
- added visual-design decisions outside Editorial authority.

### 3. Edit structure

Remove or repair:

- repeated ideas;
- delayed premise;
- missing logical steps;
- unearned payoff;
- weak transitions;
- page copy that duplicates the caption;
- paragraphs that belong on another page or should be cut.

### 4. Edit language

Improve:

- specificity;
- verb strength;
- sentence rhythm;
- pronoun clarity;
- tonal consistency;
- Chinese naturalness;
- display-copy memorability;
- qualifiers and disclosures;
- CTA relevance.

Reject false drama, generic inspiration language, unexplained jargon, and inflated claims.

### 5. Inspect speaker and reality position

Ask:

- What would a reasonable reader think actually happened?
- Is that belief accurate?
- Is the fictional, conceptual, hypothetical, or speculative status clear before the reader relies on it?
- Does a late disclaimer attempt to undo a misleading narrative?

If the main premise misleads, rewrite the premise—not only the disclaimer.

### 6. Produce an edit comparison

For material edits, show:

- original passage;
- issue;
- revised passage;
- reason;
- authority affected.

### 7. Return the edited exact draft

Preserve approved meaning. Any material change to architecture, Frame Script, or claim boundary returns to the responsible upstream Skill.


## Self-check

- Did the pass inspect the draft rather than writer intent?
- Did it challenge the main premise and reader interpretation?
- Are edits traceable to communication consequences?
- Is the edited version still faithful to Treatment, architecture, and Frame Scripts?
- Has visual stage leakage been removed?
- Are unresolved upstream issues explicitly returned?

## Failure routing

- Treatment fidelity failure → Development through Editorial Director;
- architecture failure → Content Architecture;
- Frame Script failure → Frame Script;
- source / claim / rights issue → Development Research / Claims Rights;
- exact typo and consistency pass → Proofreading.
