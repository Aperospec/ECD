# Copy Editing Skill

## Purpose

Copy Editing challenges and improves a completed draft. It is not a second drafting pass that merely polishes sentences.

It must inspect the actual draft against authoritative inputs and produce visible editorial changes or a reasoned no-change finding.

## Inputs

- Greenlit Treatment;
- Core Communication Script and authority;
- Content Architecture and Core Script beat-to-page mapping;
- Frame Scripts;
- complete Copywriting Return;
- Concept Reframing Record and source posture when applicable;
- Evidence Obligation, actual claim, source, attribution, and rights conditions;
- audience and platform contract;
- Editorial Director assignment.

## Method

### 1. Reconstruct intended communication

State:

- core proposition;
- approved Core Communication Script;
- essential beats and payoff;
- audience movement;
- speaker position;
- factual / conceptual status;
- source posture;
- role of each page and publication section.

### 2. Compare draft to authority

Check whether the draft:

- changed the project premise;
- changed or weakened the approved Core Script;
- overemphasized a side example;
- removed an essential beat or replaced the payoff;
- added unsupported capability or result claims;
- converted speculation into fact;
- converted a fictional or hypothetical scene into an apparent personal experience;
- introduced sales, tutorial, review, or promotional framing excluded by Treatment;
- added visual-design decisions outside Editorial authority;
- turned a Discovery Signal into a source-centered article;
- closely followed source wording, paragraph order, examples, or rhetorical structure.

### 3. Inspect unnecessary source and validation language

For Concept Reframing with Discovery Signal only, remove language that does not serve the approved communication, including default:

- creator name or handle;
- `灵感来源于`;
- source link;
- `我们实测` or `我们没有实测`;
- `这只是概念创作`;
- `画面并非真实运行`;
- infringement disclaimers;
- future productization or sales preview.

Retain or add such language only when:

- the ECD explicitly requested it;
- the final work has a material factual dependency;
- quotation or direct-use material requires it;
- rights, platform, or accurate audience interpretation requires it.

Do not create a false problem and then solve it with a disclaimer.

### 4. Edit structure

Remove or repair:

- repeated ideas;
- delayed premise;
- missing logical steps;
- unearned payoff;
- weak transitions;
- page copy that duplicates the caption;
- paragraphs that belong on another page or should be cut;
- page adaptation that obscures the aligned Core Script.

### 5. Edit language

Improve:

- specificity;
- verb strength;
- sentence rhythm;
- pronoun clarity;
- tonal consistency;
- Chinese or English naturalness;
- display-copy memorability;
- qualifiers and disclosures only where materially required;
- CTA relevance.

Reject false drama, generic inspiration language, unexplained jargon, inflated claims, source-defensive prose, and close paraphrase.

### 6. Inspect speaker and reality position

Ask:

- What would a reasonable reader think actually happened?
- Is that belief accurate relative to the approved script?
- Is any fictional, conceptual, hypothetical, or speculative status clear when it needs to be?
- Is a late disclaimer attempting to undo a misleading narrative?
- Conversely, is the draft over-explaining provenance or non-testing despite making no such claim?

If the main premise misleads, rewrite the premise—not only the disclaimer.

If no misleading premise exists, remove unnecessary defensive language.

### 7. Inspect Concept Reframing independence

Ask:

- Does the new piece have its own angle and progression?
- Are its examples and scenarios independently created?
- Is the language materially different from the source?
- Could the piece stand without source identity?
- Has the final post become a disguised summary or rewrite of the original source?

Return source-specific expression to the responsible upstream method rather than cosmetically paraphrasing it.

### 8. Produce an edit comparison

For material edits, show:

- original passage;
- issue;
- revised passage;
- reason;
- authority affected.

### 9. Return the edited exact draft

Preserve approved meaning. Any material change to Core Script, architecture, Frame Script, or claim boundary returns to the responsible upstream Skill.

## Self-check

- Did the pass inspect the actual draft rather than writer intent?
- Did it compare against the approved Core Communication Script?
- Did it challenge the main premise and reader interpretation?
- Did it remove unnecessary source, testing, concept, or productization language?
- Did it preserve genuinely required attribution or disclosure?
- Is the new work independent from source expression?
- Are edits traceable to communication consequences?
- Is the edited version still faithful to Treatment, Core Script, architecture, and Frame Scripts?
- Has visual stage leakage been removed?
- Are unresolved upstream issues explicitly returned?

## Failure routing

- Treatment fidelity failure → Development through Editorial Director;
- Core Script failure or requested change → Core Communication Script;
- architecture or beat mapping failure → Content Architecture;
- Frame Script failure → Frame Script;
- source posture, factual dependency, direct-use, or rights issue → Development Research / Claims Rights;
- exact typo and consistency pass → Proofreading.
