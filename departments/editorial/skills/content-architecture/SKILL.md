# Content Architecture Skill

## Purpose

Content Architecture organizes how meaning progresses.

It does not write final prose, decide final visual style, or split source material mechanically into pages.

## Inputs

- Greenlit Treatment and Development decisions;
- audience, platform, deliverables, and viewing conditions;
- source, claim, disclosure, and rights boundaries;
- user feedback;
- Editorial Director assignment.

## Method

### 1. Define audience movement

State:

- what the audience knows or assumes before;
- what they should notice first;
- what must become clear next;
- what evidence or explanation changes understanding;
- what remains after the final page.

### 2. Choose communication mode

Select one or a deliberate mix:

- explanatory;
- narrative;
- demonstrative;
- procedural;
- comparative;
- evidentiary;
- thematic / associative;
- persuasive;
- speculative.

Multiple pages do not automatically require chronological narrative.

### 3. Choose the minimum sufficient format

Decide whether the project needs:

- one screen;
- cover plus one body page;
- short carousel;
- extended sequence;
- evidence-led post;
- mixed format.

Do not add pages to create a feeling of completeness.

### 4. Build the sequence map

For every page or beat define:

```markdown
Page:
Editorial job:
Audience state before:
Internal Semantic Proposition:
Audience state after:
Required source / evidence:
Relationship to previous and next page:
Why this page is necessary:
```

Each page has one primary editorial job.

### 5. Test sequence integrity

- Remove each page: what is lost?
- Merge adjacent pages: does meaning improve or collapse?
- Are two pages making the same point?
- Is the payoff earned?
- Does the cover promise the actual sequence?
- Does the sequence rely on information the audience never received?

### 6. Define Frame Script assignments

Translate each Internal Semantic Proposition into a clear Frame Script task without deciding final composition, palette, typeface, or image style.

## Output

```markdown
# Content Architecture Return

Project:
Audience movement:
Communication mode:
Format recommendation:
Overall Communication Logic:
Sequence map:
Page-by-page editorial jobs:
Evidence / source placement:
Disclosure placement:
Pages removed or merged:
Alternative structures considered:
Frame Script assignments:
Open copy questions:
Open visual questions:
Self-check:
Recommended Director disposition:
```

## Self-check

- Is the sequence the minimum sufficient one?
- Does each page change understanding?
- Are modes chosen deliberately rather than by carousel formula?
- Are evidence and disclosures placed where they matter?
- Have copy and visual decisions remained appropriately open?

## Failure routing

- Treatment lacks a coherent proposition → Development through Editorial Director;
- source or evidence cannot support the sequence → Development Research / Claims Rights;
- page cannot become visible or experiential → Frame Script;
- visual format constraints invalidate the architecture → return through Producer for bounded Visual consultation.
