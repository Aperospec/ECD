# Copywriting Skill

## Purpose

Copywriting turns approved Core Communication Script meaning, page architecture, and Frame Scripts into precise audience-facing language.

It does not redesign the concept, invent the core progression, decide visual styling, closely paraphrase a discovery source, or add attribution and defensive explanations that the approved publication does not need.

## Inputs

- Greenlit Treatment;
- Core Communication Script and authority / gate mode;
- Content Architecture Return and Core Script beat-to-page mapping;
- Frame Scripts and Written Visual Requirements;
- audience, platform, language, and format;
- Concept Reframing Record and source posture when applicable;
- Evidence Obligation, claim, attribution, disclosure, and rights conditions actually applicable;
- Editorial Director assignment.

## Method

### 1. Establish the speaker contract

Define:

- who is speaking;
- from what knowledge position;
- whether the content is real experience, documented fact, interpretation, hypothetical example, fictional scene, concept visualization, speculation, demonstration, independent Concept Reframing, or mixed;
- what degree of certainty the speaker can honestly claim.

This position must be clear when it materially affects interpretation. Do not add a disclaimer when the copy makes no misleading factual or reliability claim.

### 2. Preserve the Core Communication Script

For every major copy section, identify the approved Core Script beat it serves.

Copy may sharpen language, rhythm, and platform fit. It may not:

- invent a new central story or argument;
- remove an essential beat;
- replace the payoff;
- change the speaker or reality position;
- turn a Discovery Signal into a source-centered post.

### 3. Define copy roles

For every page or publication component identify:

- dominant statement;
- deck or explanation;
- evidence label when required;
- source or limitation only when required;
- transition or sequence marker;
- CTA or closing question.

Do not repeat one sentence at multiple sizes.

### 4. Draft for display and reading

Page copy should work at visual scale. Publication copy may carry deeper explanation.

Prefer:

- concrete nouns and verbs;
- one clear idea per display unit;
- meaningful contrast;
- compression without vagueness;
- native Chinese or English rhythm rather than translated marketing syntax;
- public explanation only where it serves the approved communication.

### 5. Apply Concept Reframing defaults

When source posture is Discovery Signal and the work uses original examples, copy, and visuals:

- write the topic as the studio's independent concept-sharing piece;
- do not mention the original creator or source by default;
- do not add `灵感来源于`;
- do not state `我们实测` or `我们没有实测`;
- do not add `这只是概念创作` or `画面并非真实运行` unless the approved script actually creates that ambiguity;
- do not mention future Skill sales or productization when the current project excludes it;
- do not echo source wording, paragraph order, examples, or rhetorical structure.

When source posture is Factual Dependency or Direct-use Material, include only the source, attribution, or limitation language approved by Development and Editorial Director.

### 6. Write page copy from Frame Scripts

For every page:

- make the primary message legible alone;
- ensure support copy adds rather than repeats;
- preserve names, numbers, actual claims, evidence, and qualifiers that are genuinely required;
- preserve the aligned Core Script beat;
- avoid describing exact layout or style.

### 7. Write complete publication copy

When required, include:

- title;
- opening hook;
- development;
- explanation or evidence when part of the approved script;
- payoff;
- attribution or disclosure only when required;
- closing prompt;
- tags only when useful.

Do not write a tutorial if the approved Treatment is concept sharing. Do not introduce future sales language when the project excludes it.

### 8. Produce alternatives only where consequential

Offer alternatives for headline, opening, or closing when they represent materially different rhetorical choices. Do not create ten near-duplicates.

## Self-check

- Is the copy faithful to the approved Core Communication Script?
- Is the speaker position accurate without unnecessary explanation?
- Does each page have one primary message?
- Does copy match the approved Frame Script?
- Are actual claims no stronger than evidence?
- Is attribution or disclosure present only when materially required?
- Is Discovery Signal absent from public copy unless intentionally activated?
- Is the wording independent from source expression?
- Has visual design remained Deferred?
- Does the language sound written for the actual audience?

## Failure routing

- Core Script weak or materially changed → Core Communication Script;
- sequence or page mapping weak → Content Architecture;
- Frame Script cannot support the intended message → Frame Script;
- source / claim / direct-use boundary unresolved → Development Research / Claims Rights;
- draft needs structural, source-position, or truth-position challenge → Copy Editing;
- exact-text verification → Proofreading.
