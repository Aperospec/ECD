# Copywriting Skill

## Purpose

Copywriting turns approved meaning and Frame Scripts into precise audience-facing language.

It does not redesign the concept, decide visual styling, or use fictional certainty to manufacture engagement.

## Inputs

- Greenlit Treatment;
- Content Architecture Return;
- Frame Scripts and Written Visual Requirements;
- audience, platform, language, and format;
- source, claim, attribution, disclosure, and rights conditions;
- Editorial Director assignment.

## Method

### 1. Establish the speaker contract

Define:

- who is speaking;
- from what knowledge position;
- whether the content is real experience, documented fact, interpretation, hypothetical example, fictional scene, concept visualization, speculation, or demonstration;
- what degree of certainty the speaker can honestly claim.

This position must be visible in the main narrative when it affects interpretation.

### 2. Define copy roles

For every page or publication component identify:

- dominant statement;
- deck or explanation;
- evidence label;
- source or limitation;
- transition or sequence marker;
- CTA or closing question.

Do not repeat one sentence at multiple sizes.

### 3. Draft for display and reading

Page copy should work at visual scale. Publication copy may carry deeper explanation.

Prefer:

- concrete nouns and verbs;
- one clear idea per display unit;
- meaningful contrast;
- compression without vagueness;
- native Chinese rhythm rather than translated marketing syntax;
- clear disclosure close to the claim it qualifies.

### 4. Preserve reality position

Do not write a concept scene as if it literally happened to the user unless the user confirmed it did.

Invalid pattern:

```text
I wake up every day and discover impossible events...
[long factual-sounding narrative]
...
This was only a concept.
```

Valid approaches include:

- `我设想了一只……`;
- `如果有一天……`;
- `这组概念图想象的是……`;
- clearly framed fictional narration whose status is apparent from the beginning.

A disclaimer supports clarity; it does not reverse a misleading main premise.

### 5. Write page copy from Frame Scripts

For every page:

- make the primary message legible alone;
- ensure support copy adds rather than repeats;
- preserve names, numbers, claims, evidence, and qualifiers;
- avoid describing the exact layout or style.

### 6. Write complete publication copy

When required, include:

- title;
- opening hook;
- development;
- explanation or evidence;
- payoff;
- disclosure / attribution;
- closing prompt;
- tags only when useful.

Do not write a tutorial if the approved Treatment is concept sharing. Do not introduce future sales language when the Treatment excludes it.

### 7. Produce alternatives only where consequential

Offer alternatives for headline, opening, or closing when they represent materially different rhetorical choices. Do not create ten near-duplicates.

## Self-check

- Is the speaker position honest from the start?
- Does each page have one primary message?
- Does copy match the approved Frame Script?
- Are claims no stronger than evidence?
- Is disclosure placed where it affects interpretation?
- Has visual design remained Deferred?
- Does the language sound written for the actual audience?

## Failure routing

- sequence or page job weak → Content Architecture;
- Frame Script cannot support the intended message → Frame Script;
- source / claim boundary unresolved → Development Research / Claims Rights;
- draft needs structural and truth-position challenge → Copy Editing;
- exact-text verification → Proofreading.
