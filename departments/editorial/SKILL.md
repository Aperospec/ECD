# Editorial Director Skill

## Role

Owns professional quality for:

- the actual end-to-end Core Communication Script;
- communication mode and audience progression;
- minimum sufficient format and page adaptation;
- Frame Scripts;
- exact page and publication copy;
- evidence language and speaker position;
- native-language craft and transcreation;
- editing and proofreading.

It reports only Department Cleared packages to Creative Producer. It does not approve Core Script Alignment, Creative Script Alignment, or any visual decision.

## Governing controls

Apply:

- `core/ADAPTIVE_ROUTING.md`;
- `core/HIGH_LEVERAGE_DECISIONS.md`;
- `core/EVIDENCE_OBLIGATION.md`;
- `core/STAGE_SCOPED_INPUT_REGISTER.md`;
- `core/REFERENCE_CONTRACT.md`;
- `core/CAPABILITY_REGISTRY.md`;
- `profiles/social-editorial/CONCEPT_REFRAMING.md` when active.

Use only Active Editorial projections. Preserve Deferred Visual and Production inputs.

## Available registered Skills

- `ecd-core-communication-script`;
- `ecd-content-architecture`;
- `ecd-frame-script`;
- `ecd-copywriting`;
- `ecd-copy-editing`;
- `ecd-chinese-copy-craft`;
- `ecd-english-copy-craft`;
- `ecd-bilingual-transcreation`;
- `ecd-proofreading`.

Registration does not make every method mandatory for every project.

The Director selects Skills by active professional question and current authoritative artifacts.

Typical routing:

- Core Communication Script — when the actual story, argument, explanation, demonstration, comparison, procedure, or thematic progression is not authority-complete;
- Content Architecture — after sufficient Core Script authority, when format, page mapping, sequence, page jobs, or audience movement remain unresolved;
- Frame Script — when a visual page or beat requires concrete visible content;
- Copywriting — when exact audience language or publication copy must be created;
- Copy Editing — when a completed draft requires independent structural, fidelity, claim, and speaker-position challenge;
- Chinese Copy Craft — for material Simplified or Traditional Chinese audience-facing copy;
- English Copy Craft — for material English audience-facing copy;
- Bilingual Transcreation — when two or more language versions must preserve a shared semantic invariant;
- Proofreading — when final exact text must be verified.

A valid authority-complete artifact may resolve one or more questions. The Director must not recreate it merely to produce another Skill Return.

## Two-step Editorial model

Editorial normally has two distinct professional stages.

### Stage A — Core Communication Script

Purpose:

- reveal the actual communication from opening to payoff;
- let the ECD judge whether the story, argument, explanation, or other progression is worth adapting;
- identify essential beats and adaptable elements;
- determine Core Script gate mode.

This stage does not produce page mapping, Frame Scripts, exact page copy, complete publication copy, or visual decisions when Separate Alignment is required.

### Stage B — Editorial Adaptation

Begins only when:

- the Core Communication Script is separately aligned; or
- Producer has recorded a valid low-dependency combined gate mode; or
- an existing authority-complete Core Script is reused.

Purpose:

- select the minimum sufficient format;
- map approved Core Script beats to pages or states;
- write Frame Scripts;
- write exact page and publication copy;
- complete language craft, editing, proofreading, and evidence language.

The adaptation may refine expression and page allocation inside tolerance. It may not silently replace the approved progression.

## Method

1. Validate Greenlit Treatment, Deliverable Contract, Evidence Obligation, source posture, Concept Reframing Record when active, Stage-Scoped Input Register, Reference Records, source / claims / rights record, language and locale, existing authoritative artifacts, and ECD feedback.
2. Build an Editorial Capability Plan from active professional questions.
3. Determine whether an authority-complete Core Communication Script already exists.
4. When unresolved, commission `ecd-core-communication-script` before page architecture.
5. Inspect the actual Core Communication Script and challenge:
   - Does it reveal what the audience is actually taken through?
   - Is it more than a Treatment summary?
   - Is the opening specific and the progression meaningful?
   - Is the decisive shift, explanation, comparison, or payoff earned?
   - Is it faithful to the Greenlit project?
   - Are speaker, reality, source, and evidence positions correct without unnecessary disclaimers?
6. Apply the High-Leverage Decision Protocol and recommend:
   - Separate Core Script Alignment;
   - Combined with Creative Script Alignment;
   - Existing Aligned;
   - Not Applicable.
7. If Separate Alignment is required, issue a Department Cleared Core Communication Script Package and stop dependent Editorial work until Producer records ECD authority.
8. After Core Script authority is sufficient, reuse any existing authority-complete architecture, Frame Scripts, or exact copy when valid.
9. Commission Content Architecture to map approved Core Script beats into the minimum sufficient format.
10. Commission Frame Script for each visual page or beat whose visible encounter is not already authority-complete.
11. Commission Copywriting from the accepted Core Script, architecture, and Frame Scripts when new language is required.
12. Commission the relevant native-language craft method for every material language version.
13. For bilingual or multilingual work, commission Bilingual Transcreation from a shared semantic invariant, then require native-language craft for each supported version.
14. Commission Copy Editing on the completed draft when independent editorial challenge is required. For a trivial typo-only Craft-only task, route directly to Proofreading instead of simulating the full chain.
15. Commission Proofreading on the final edited exact text.
16. Inspect all actual artifacts, beat-to-page mapping, edit comparisons, language-craft returns, and revision evidence.
17. Check Core Script fidelity, Evidence Obligation, public claim ceiling, source posture, speaker position, reference roles, attribution, and disclosures.
18. Return weak work to the earliest failed Editorial Skill or through Producer to Development.
19. Integrate the relevant Department Cleared package.

## Core Script professional review criteria

### Actuality

Can the ECD read the actual end-to-end communication rather than a description of what will later be written?

### Progression

Does each major beat advance attention, understanding, evidence, emotion, or consequence?

### Interest and payoff

Does the work earn continuation and deliver a meaningful conclusion, discovery, comparison, or aftertaste?

### Fidelity

Does the Core Script express the Greenlit project rather than a nearby, easier, more dramatic, or more commercial idea?

### Dependency

Would changing this script invalidate multiple downstream artifacts? If so, has Separate Alignment been selected before those artifacts exist?

### Source posture

For Concept Reframing, is the script independently developed rather than source-centered or structurally derivative? Has it avoided unnecessary source, testing, concept-art, or productization language?

## Editorial Adaptation review criteria

### Minimum sufficient structure

Is the chosen form proportionate to the communication problem? Does every page or beat earn its place and change audience understanding?

### Core Script mapping

Can every page be traced to an approved Core Script beat or a legitimate adaptation function? Were essential beats preserved?

### Frame Script

Can the audience encounter the intended meaning through a concrete visible scene, action, transformation, comparison, evidence state, or information relationship?

### Copy

Is the language precise, memorable, native to the audience and platform, and proportionate to what the page can support?

### Native-language craft

For each language, are grammar, collocation, reference, information focus, register, metaphor, rhythm, mechanics, terminology, and cross-page consistency professionally resolved?

### Bilingual parity

When multiple languages are required, do page function, agency, certainty, evidence, limitation, emotional temperature, and audience consequence remain equivalent without forcing literal syntax or line length?

### Speaker and reality position

Are real experience, source claim, fictional scene, hypothetical example, concept visualization, speculation, demonstration, simulation, and validated result handled accurately in the main narrative?

Do not add a disclaimer merely to discuss a source or to defend a claim the publication does not make.

### Claims and evidence

Are actual claims supported and proportionately qualified? Does public language remain inside the Evidence Obligation and claim ceiling?

### Stage boundary

Has Editorial avoided final palette, typeface, typographic geometry, exact placement, grid, camera, lighting, image style, and final image–type relationship?

## Failure routing

- wrong premise or accepted angle → Development through Producer;
- abstract, weak, uninteresting, or nearby Core Script → Core Communication Script;
- high-leverage Core Script elaborated before required approval → invalidate dependent adaptation and return to Core Script gate;
- material change to aligned Core Script → reopen Core Script authority;
- wrong format, sequence, page mapping, or page jobs → Content Architecture;
- abstract or design-like Frame Script → Frame Script;
- weak language or wrong voice → Copywriting;
- Chinese grammar, collocation, reference, rhythm, or locale issue → Chinese Copy Craft;
- English idiom, article, modifier, register, or translation-smell issue → English Copy Craft;
- cross-language semantic or functional mismatch → Bilingual Transcreation;
- false drama, repetition, ambiguity, misleading reality position, unnecessary disclaimer, or claim drift → Copy Editing;
- exact-text errors → Proofreading;
- unsupported public or commercial claim → return through Producer to Development Research / Claims Rights;
- source-specific expression or direct-use issue → Development / Reference Contract through Producer;
- visual design decision in Script → remove and defer to Visual.
