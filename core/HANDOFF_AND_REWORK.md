# Handoff and Rework — V3.2

## Formal handoff chain

```text
Specialist Return or validated existing artifact
→ Department Director Review
→ Department Cleared Package
→ Creative Producer Integrated Review
→ Producer Cleared use
→ ECD decision when required
→ Producer activates next state and stage projections
```

No other path is authoritative.

Apply `ADAPTIVE_ROUTING.md`, `HIGH_LEVERAGE_DECISIONS.md`, `EVIDENCE_OBLIGATION.md`, `STAGE_SCOPED_INPUT_REGISTER.md`, and `REFERENCE_CONTRACT.md` to every formal handoff.

## Specialist-to-Director handoff

Required:

- registered Skill identity and version;
- professional question served;
- task and authority;
- actual artifact;
- Stage-Scoped Input IDs used;
- High-Leverage Decision consequence when applicable;
- Evidence Obligation consequence;
- Concept Reframing / source posture when applicable;
- Reference roles used and prohibited transfers;
- method evidence;
- decisions introduced;
- unresolved questions;
- self-check;
- recommended disposition.

The Specialist cannot mark its work Department Cleared.

## Valid existing artifact handoff

When no new Specialist pass is needed because a valid artifact already answers the question, record:

- artifact and version;
- quality and authority state;
- dependency validation;
- unresolved feedback;
- current applicability;
- Stage-Scoped Input, source posture, and Reference conditions inherited;
- reason the earlier artifact may be reused.

Artifact title alone is not authority evidence.

## Director-to-Producer handoff

Required:

- Department Cleared package;
- signed Department Review Record;
- active professional questions and their resolution;
- selected Specialist Returns;
- Skills omitted, reused, or combined and reasons;
- Adaptive Route and complexity profile;
- High-Leverage Decision Record and gate mode;
- Evidence Obligation and public claim ceiling;
- Concept Reframing / source posture;
- authoritative dependencies and versions;
- Stage-Scoped Input IDs resolved, activated, Deferred, conflicted, or superseded;
- Source / Reference Records, active roles, permissions, evidence context, and prohibited use;
- decision delta;
- feedback closure;
- limitations and risks;
- Director recommendation;
- requested next use.

Producer returns a package that contains only a Director assertion without inspectable evidence.

## Core Communication Script handoff

A Department Cleared Core Communication Script Package must identify:

- Greenlit Treatment dependency;
- actual complete communication progression;
- communication form;
- essential and adaptable beats;
- speaker / reality / source position;
- dependency fan-out;
- Core Script gate mode;
- dependent artifacts kept inactive;
- Director recommendation.

When Separate Alignment is required, this package may be handed only to Producer for an ECD Core Script Alignment object. It may not flow directly into Content Architecture or Frame Script.

When gate mode is Combined, Producer must record why dependent work is low risk and ensure the later ECD-facing Creative Script object shows Core Script and adaptation as separate scopes.

## Producer-to-ECD release

Required:

- complete Decision Object in the primary conversation;
- Department Director recommendation;
- Producer recommendation;
- relevant alternatives or tradeoff;
- decision-relevant High-Leverage, Evidence Obligation, source, reference, rights, language, or limitation information;
- approval scope and exclusions;
- consequence;
- one explicit request.

The ECD is not asked to inspect raw internal worksheets or perform first-line Department QA.

## Producer-to-Department assignment

Required:

- current Project State;
- Deliverable Contract;
- Adaptive Route and complexity profile;
- High-Leverage Decision Record and Core Script gate mode;
- Evidence Obligation and claim ceiling;
- Concept Reframing / source posture;
- authoritative artifacts and versions;
- ECD decisions and locks;
- Active and Deferred Stage-Scoped Input IDs with original wording and authority class;
- active Source / Reference Records, roles, rights, evidence context, and prohibited transfer;
- professional questions to resolve;
- requested Department outcome;
- authority boundary;
- acceptance criteria;
- evidence required;
- cross-department dependencies;
- return conditions;
- expected ECD gate.

## Decision delta

Every formal artifact records:

- inherited authoritative decisions;
- decisions added by this artifact;
- decisions refined without changing meaning;
- decisions proposed to change;
- decisions removed;
- open decisions;
- dependencies;
- affected Stage-Scoped Input IDs, source posture, and Reference conditions.

A downstream Department may add and refine within authority.

A change or removal of an upstream authoritative decision requires Producer to reopen the earliest affected artifact and invalidate only dependent authority.

A material change to the actual communication progression reopens the Core Communication Script, not automatically the Greenlit Treatment.

## Feedback closure

Statuses:

- Open
- Assigned
- In Rework
- Partially Resolved
- Resolved
- Conflict requiring ECD decision
- Superseded

Closure requires revised evidence and Director verification. A statement such as `已修改` is not closure.

## Rework routing

Return to the earliest object where the defect became true.

Typical routing:

- weak or wrong opportunity / premise → Creative Strategy or Concept Development;
- wrong Discovery Signal / Factual Dependency / Direct-use classification → Producer / Development;
- wrong Evidence Obligation, unsupported claim, validation, or rights problem → Research Verification or Claims Rights;
- wrong input authority, projection, or repeated-question behavior → Creative Producer / Stage-Scoped Input Register;
- reference role, transfer, permission, or evidence-context problem → Reference Contract / Claims Rights / responsible Department;
- weak, abstract, uninteresting, or incorrect actual progression → Core Communication Script;
- missing required Core Script authority → Producer / Authority correction;
- page mapping, format, sequence, or page-job problem → Content Architecture;
- abstract or unvisualizable page → Frame Script;
- weak, misleading, source-defensive, or false-positioned language → Copywriting / Copy Editing;
- Chinese native-language problem → Chinese Copy Craft;
- English native-language problem → English Copy Craft;
- bilingual function or semantic parity problem → Bilingual Transcreation;
- typo, name, punctuation, exactness → Proofreading;
- generic or source-derivative visual idea → Visual Concept;
- sequence staging or repetition → Storyboard / Sequence;
- layout, hierarchy, grid, crop, image–type relation → Editorial Design;
- typeface, line break, spacing, mixed script → Typography;
- scene, camera, light, image continuity → Image Direction;
- generation quality → Image Production;
- final layout implementation → Finished Art / Production Typesetting;
- dimensions, export, safe area, file integrity → Technical QA;
- ambiguous approval or illegal transition → Producer / Project State.

## Rework stop condition

Every Rework Brief defines what evidence will prove closure. Internal iteration stops when:

- acceptance criteria are met;
- a genuine ECD decision is required;
- a capability, rights, information, evidence, validation, scope, or feasibility blocker remains;
- the Department recommends abandoning the route.

## Dependency-preserving Core Script rework

When the ECD rejects or revises the Core Communication Script:

- preserve Greenlight unless the feedback changes the accepted project premise or boundaries;
- keep source, research, Evidence Obligation, and Concept Reframing work that remains valid;
- invalidate or mark provisional only Content Architecture, Frame Scripts, copy, and visual work that depend on the rejected progression;
- after approval, revalidate and reuse any dependent material that still fits;
- do not rebuild unrelated work for ceremony.

## No downstream rescue

Do not use:

- a Treatment summary as a substitute for an actual Core Communication Script;
- page architecture, Frame Scripts, or copy to hide an unconfirmed high-leverage progression;
- disclaimer as a substitute for truthful speaker position;
- unnecessary attribution or non-testing language as a substitute for clear independent Concept Reframing;
- engagement enthusiasm as a substitute for factual evidence;
- one demonstration as a substitute for commercial validation;
- repeated ECD questions as a substitute for carrying registered inputs forward;
- style imitation as a substitute for original visual development;
- smaller typography as a substitute for Editorial compression;
- opaque cards as a substitute for composition;
- new imagery as a substitute for a weak Frame Script;
- final retouch as a substitute for a weak visual concept;
- Production convenience as a reason to alter approved meaning.
