# High-Leverage Decision Protocol — V3.2

Constitution clauses: `SEM-048`.

## Purpose

A decision that controls several dependent professional artifacts must be exposed and confirmed before expensive dependent elaboration begins.

This protocol prevents the studio from first revealing the actual story, argument, demonstration, or other governing progression only after page architecture, Frame Scripts, exact copy, or visual work have already been produced.

It does not require a new ECD gate for every project. It requires the smallest decision surface that protects downstream work from avoidable invalidation.

## High-leverage test

Producer and the responsible Department Director assess whether an unresolved decision:

- determines the actual story, argument, explanation, comparison, demonstration, or procedural progression;
- controls several downstream pages, beats, copy units, image states, or production assets;
- has not yet been shown to the ECD in a form that can be judged directly;
- would invalidate substantial dependent work if changed;
- is primarily subjective or strategic rather than routine craft;
- cannot be safely inferred from an authority-complete artifact already supplied by the ECD.

If several of these conditions are true, the decision receives an ECD-facing alignment object before dependent elaboration.

## Social Editorial application: Core Communication Script

After Greenlight, Editorial first resolves the actual end-to-end communication progression through a `Core Communication Script`.

The Core Communication Script is broader than a narrative screenplay. It may be:

- narrative;
- explanatory;
- demonstrative;
- comparative;
- procedural;
- evidentiary;
- thematic / associative;
- persuasive;
- speculative;
- a deliberate mixed form.

It must show what the audience will actually be taken through from opening to payoff. A synopsis stating only what the studio intends to discuss is insufficient.

The Core Communication Script establishes, as applicable:

- opening condition or question;
- actual progression of ideas, events, demonstrations, or evidence;
- decisive shift, discovery, contrast, or turning point;
- ending, payoff, consequence, or aftertaste;
- speaker and reality position;
- essential beats that downstream adaptation must preserve;
- elements that may be compressed, expanded, reordered, or expressed differently during page adaptation.

It does not decide:

- final page count;
- page-to-beat mapping;
- Frame Scripts;
- exact page copy;
- complete publication copy;
- palette, typography, layout, camera, lighting, image style, or final visual execution.

## Gate modes

Producer records one of four Core Script gate modes.

### Separate Alignment

Use when changing the Core Communication Script would materially invalidate multiple downstream artifacts or when the communication progression is a principal creative judgment the ECD has not yet seen.

The studio produces and reviews the Core Communication Script, releases a complete `Core Script Alignment` Decision Object, and stops. Page architecture, Frame Scripts, exact copy, and publication copy remain inactive until approval.

### Combined with Creative Script Alignment

Use only when dependency cost is genuinely low, such as:

- a single-screen or otherwise narrow communication object;
- an authority-complete script already supplied by the ECD;
- a direct, short adaptation in which page mapping and exact copy do not create substantial dependent work;
- a Compact project where revising the core progression would not invalidate meaningful downstream production.

The ECD-facing Creative Script object must still show the Core Communication Script as a distinct section before the adaptation. The combined decision scope must explicitly include it.

### Existing Aligned

Use when an identifiable Core Communication Script already has valid ECD authority and remains current. Reuse it; do not recreate it for ceremony.

### Not Applicable

Use only when there is no meaningful communication progression to approve, such as a purely local correction to an already-authorized artifact. Record why.

## Dependency rule

When Separate Alignment is required, the following remain inactive before Core Script approval:

- Content Architecture that maps the progression into pages;
- Frame Scripts;
- exact page copy;
- complete publication copy;
- Visual Development;
- Production.

Low-cost exploration may be used only to improve the Core Communication Script itself and must not become a hidden page package.

## Adaptation after alignment

After Core Script approval, Editorial may:

- choose the minimum sufficient format;
- map approved beats to pages or states;
- merge, split, or compress beats within recorded tolerance;
- write Frame Scripts;
- write exact page and publication copy;
- place evidence, disclosure, and source language.

Editorial may not silently:

- replace the governing progression;
- remove an essential beat;
- substitute a nearby but easier story or argument;
- change the speaker or reality position;
- replace the payoff or conclusion;
- introduce a new central claim.

A material change reopens the Core Communication Script and requires renewed authority according to its delta.

## Decision economy

This protocol protects high-dependency work without turning every project into an extra meeting.

The gate is selected by dependency fan-out and invalidation cost, not by a fixed page count or by the mere existence of a registered Skill.

## Quality gate

Pass when:

- the actual governing progression is visible before high-cost dependent work;
- the selected gate mode matches real dependency risk;
- Compact work is not burdened with a ceremonial extra gate;
- high-leverage work is not hidden inside later Frame Scripts or copy;
- approved progression is traceable into downstream page adaptation;
- a rejected Core Script does not force avoidable rework of artifacts that should not yet have existed.
