# Visual Failure Diagnosis Regression

## Purpose

These tests verify that rejected visual output is diagnosed at the earliest failed object rather than blindly rerendered or assigned automatically to Production Artist.

Apply:

- `../art-director/references/visual-critique-and-failure-diagnosis.md`;
- `../shared/LOCK_AND_REWORK_PROTOCOL.md`.

## Hard Failures

- “ugly” feedback triggers immediate rerendering;
- the studio defends its intention instead of diagnosing the visible work;
- all final-image criticism is routed to Production Artist;
- many variants are generated to outsource diagnosis to the ECD;
- the accepted visual problem, route, anchors, and reference rules are not compared;
- the original ECD feedback is paraphrased into a different issue;
- a concept failure is called a minor style preference;
- premature batch output is retroactively treated as aligned.

## F01 — Real Failure: Six Mountain Amusement-World Scenes

Observed output:

- six to eight final-looking images;
- repeated mountain amusement-park environment;
- blue–orange evening or rainy grading;
- recurring dark-coated figure;
- family, care, meal, campfire, and walking vignettes;
- recognizable rides and cabins;
- weak world topology across pages;
- images resemble tourism promotion or sentimental film stills.

Accepted visual intent:

- a life archive becomes an explorable life-world;
- the whole world is primary;
- paths, regions, height, return, density, and unfinished space organize life;
- amusement-world reference contributes structure and experience, not literal commercial rides;
- people demonstrate lived use and scale.

Expected diagnosis:

- Visual Problem failure: explorable life-world became emotional scenes in a park;
- Reference Transfer failure: surface objects copied, underlying structure weakened;
- Visual Metaphor failure: source domain became literal setting;
- Concept Route failure: world-led system became character-led vignette;
- Storyboard / Sequence failure: repeated grade and staging replaced progression;
- possible Production issues are secondary.

Expected rework:

- stop batch production;
- mark output non-authoritative if produced before Anchor Gate;
- reopen Visual Problem, Reference Reading, Metaphor Map, and Concept Route as needed;
- preserve Script and valid visual constraints;
- produce low-cost route / formal studies;
- create revised anchors;
- request alignment before any new batch.

## F02 — Correct Route, Wrong Anchor

Input:

- selected route is conceptually correct;
- low-cost Storyboard is coherent;
- high-fidelity World Anchor becomes too commercial and copies the reference composition.

Expected owner:

- Anchor Keyframe / Art Director, possibly reference-transfer check;
- do not reopen Script or entire Concept Route unless diagnosis shows route itself caused the drift.

## F03 — Correct Anchor, Wrong Final Batch

Input:

- accepted anchors establish world-led composition and small people;
- final screens enlarge characters and flatten the environment.

Expected owner:

- Production Artist;
- anchors and Art Direction remain valid;
- regenerate / reassemble only affected screens under anchor fidelity checks.

## F04 — Design Comp Failure

Input:

- image anchors are strong;
- text hierarchy in the Comp is timid, body copy too small, and generic text boxes cover the environment.

Expected owner:

- Representative Design Comp / Art Director;
- do not blame image generation or copy unless copy genuinely cannot fit.

## F05 — Storyboard Repetition

Input:

- every panel uses a back-facing person, central path, and sunset despite different Script beats.

Expected owner:

- Storyboard / Art Director;
- inspect Concept Route and formal studies if repetition was already encoded there;
- Color Script must create progression;
- no high-fidelity production until resolved.

## F06 — Metaphor Is Superficial

Input:

- one ride represents growth;
- one ride represents loss;
- one ride represents memory;
- world does not function beyond labeled attractions.

Expected owner:

- Visual Metaphor Map;
- return to relational invariants and world rules;
- test whether source-domain objects can be removed while meaning survives.

## F07 — Natural-Language Feedback Translation

ECD says:

> 这个看起来像旅游景区宣传片，不像我的人生档案馆。

Expected:

- preserve exact source feedback;
- translate professionally as genre drift, subject hierarchy, reference-transfer, and world-meaning failure;
- do not reduce it to “change colors” or “make it more artistic.”

## F08 — “Too Cold”

Expected diagnosis options:

- emotional distance / viewer relation;
- material and light;
- absence of lived activity;
- institutional world logic;
- character / environment relation.

Expected behavior:

- identify visible evidence;
- distinguish route-level issue from surface grading;
- ask only if subjective ambiguity remains.

## F09 — Expensive Premature Batch

Input:

- many detailed images already exist before Anchor Alignment.

Expected:

- existence and cost do not create authority;
- batch marked non-authoritative;
- useful fragments may be retained only after correct visual direction is restored;
- no pressure on ECD to approve.

## F10 — Critique Record

A valid diagnosis must include:

- ECD source feedback;
- visible observations;
- current communicated meaning;
- intended meaning;
- failure dimensions;
- first failed object;
- responsible owner;
- artifacts reopened / still valid / invalidated;
- next low-cost proof;
- remaining ECD question, if any.

## Evaluation

Pass when the studio:

- treats aesthetic rejection as valid input;
- diagnoses before rerendering;
- separates conceptual and execution failures;
- routes to the earliest failed object;
- preserves unaffected work;
- chooses a cheaper diagnostic proof before another batch.
