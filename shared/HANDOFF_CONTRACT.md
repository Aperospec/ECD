# Studio Handoff Contract

## Principle

Creative Producer coordinates authoritative transfers between internal professional modes and maintains Project State plus the Stage-Scoped Input Register.

A receiving owner may interpret accepted upstream work inside its craft, but may not silently rewrite meaning, consume Deferred inputs, or treat a natural-language intuition / reference as a finished production specification.

Every handoff must answer:

- which artifact and version are authoritative;
- which stage inputs are Active / Activated;
- which user inputs remain Deferred or Need Interpretation;
- what the receiver must produce;
- what is locked and what remains open;
- what evidence, rights, reference, language, surface, and technical conditions apply;
- what requires return rather than improvisation;
- what ECD gate is expected.

## Common Handoff Envelope

```markdown
From:
To:
Project / state reference:
Authoritative input artifact and version:
Stage-Scoped Input Register:
Activated input IDs:
Original ECD source / authority class:
Inputs needing interpretation:
Deferred inputs that must remain inactive:
Requested output artifact:
Deliverable Contract fields:
Active locks:
Open variables:
Evidence / limitation requirements:
Reference roles and prohibited transfer:
Assets / provenance state:
Production tolerances:
Known risks / blockers:
ECD gate expected:
Return conditions:
```

A handoff is invalid when the receiver must guess whether an early user statement is binding, preferred, inferred, unresolved, or not yet active.

## Development and Greenlight

### ECD → Creative Producer

The ECD may provide ideas, links, images, screenshots, rough copy, visual intuitions, references, negative examples, platform requirements, and existing artifacts in one natural-language brief.

Creative Producer:

- identifies intended use;
- registers stage projections;
- separates source from inference;
- asks only material questions;
- does not require professional terminology.

A request to make a deliverable is not itself Greenlight or visual-production authorization.

### Creative Producer → Development

Provide Active Development inputs, evidence obligation, reference / rights boundaries at Development level, and the specific premise question.

Keep Editorial, Visual, and Production inputs Deferred.

### Development → Creative Producer → ECD

Return a synthesized ECD-facing Creative Treatment, not raw internal analysis.

Present the complete Treatment and request Greenlight. Stop.

### ECD Greenlight → Creative Producer

Record:

- accepted Treatment and version;
- ECD authorization evidence;
- Development locks;
- Editorial inputs activated;
- Visual / Production inputs still Deferred;
- next stage: Creative Script.

## Editorial and Copy Handoff

### Creative Producer → Editorial Director

Transfer:

- Greenlit Treatment and valid Greenlight Record;
- Deliverable Contract;
- Activated Editorial / Copy inputs with original source and authority;
- language / locale;
- exact names, claims, evidence, limitations, and prohibited drift;
- Visual / Production inputs still Deferred.

Requested output: Creative Script with Alignment-ready copy.

### Editorial Director → Creative Producer

Return:

- communication strategy;
- minimum viable sequence;
- complete Written Visual Beats;
- Alignment-ready on-screen and body copy;
- Activated Editorial input resolution;
- Treatment Fidelity, Sequence, and Copy QA;
- material Script Alignment requirement.

No Storyboard, palette, camera, or visual production is expected.

### Script Alignment → Visual Activation

Before Art Director starts:

1. present complete ECD-facing Script when alignment is material;
2. resolve ECD decision;
3. mark Script Accepted for Handoff;
4. activate **Visual Research / Intent** inputs first;
5. preserve Production inputs as Deferred.

## Visual Development Handoffs

### Creative Producer → Art Director — Visual Intake

Transfer:

- Greenlit Treatment;
- Creative Script Accepted for Handoff;
- Written Visual Beats and exact copy;
- Deliverable Contract and viewing conditions;
- Activated Visual Research / Intent inputs;
- original ECD wording;
- reference assets, rights, intended roles, and prohibited transfer;
- existing visual artifacts and states;
- Production inputs still Deferred.

Requested first outputs:

1. Visual Problem Statement;
2. Visual Intent Record when material;
3. Reference Reading / Transfer Record;
4. Visual Metaphor Map when applicable;
5. Concept Routes and low-cost evidence.

Do not request final images at this handoff.

### Art Director → Creative Producer — Visual Direction Proposal

Return a decision-ready proposal containing:

- what Art Director believes the ECD means;
- visual problem synthesis;
- reference-role and transfer analysis;
- metaphor synthesis when relevant;
- two or three materially different Concept Routes, or a justified single route;
- low-cost visual proof;
- recommendation and tradeoffs;
- plain-language questions;
- what will happen after alignment.

### Creative Producer → ECD — Visual Direction Alignment

Show the complete proposal and representative low-cost visual evidence in the primary conversation.

The ECD should not need to know professional vocabulary. Preserve their natural-language response and record the Art Director's translation separately.

Do not activate broad production after this gate.

### ECD Visual Direction Alignment → Art Director

Transfer:

- selected route;
- ECD source response;
- professional translation;
- aligned world / scene hierarchy;
- aligned reference principles and prohibited drift;
- open formal variables.

Requested next outputs:

- composition / value / spatial / scale studies;
- Storyboard / Visual Sequence Board;
- Anchor Keyframes;
- Representative Design Comp when needed.

### Art Director → Creative Producer — Storyboard

Return the complete low-cost visual sequence with:

- Script-beat mapping;
- selected route logic;
- visual differentiation;
- world continuity;
- reference distance;
- anchor candidates;
- unresolved risks.

### Art Director → Creative Producer — Anchor / Design Proposal

Return:

- World / Cover Anchor;
- Representative Body Anchor;
- extra distinct page-class anchor only with reason;
- Representative Design Comp when typography / layout is material;
- what each proof establishes;
- relation to selected route and references;
- remaining risk;
- proposed locks and open variables.

### Creative Producer → ECD — Anchor / Design Alignment

Show actual proofs in the primary conversation.

Do not substitute a prose description, prompt list, or montage of many final-looking images.

Before this alignment passes, broad production remains inactive.

### Art Director → Creative Producer — Art Direction Package

After required alignment, return:

- Visual Problem and selected route references;
- Reference Reading and Metaphor Map;
- Storyboard;
- accepted anchors and Design Comps;
- Color Script / sequence system;
- Activated Visual input resolution;
- shared visual system;
- screen-by-screen direction;
- asset plan;
- production tolerances and forbidden drift;
- technical risks and accepted fallbacks.

## Production Handoff

### Art Direction Handoff and Activation

Before Production Artist starts, Creative Producer must:

1. confirm Visual Direction Alignment resolved when required;
2. confirm Anchor Keyframe Gate passed or valid bypass recorded;
3. confirm Design Comp passed when page design is material;
4. mark Art Direction Package Accepted for Handoff;
5. activate Deferred Production inputs;
6. log the transition.

### Creative Producer → Production Artist

Transfer:

- Accepted Creative Script and exact copy;
- selected Concept Route;
- Storyboard;
- accepted anchors;
- Representative Design Comp;
- Color Script;
- Art Direction Package;
- Activated Production inputs;
- assets, provenance, permissions, dimensions, variants, and tolerances.

Production Artist must not work directly from the raw reference as the governing prompt.

### Production Artist → Creative Producer

Return:

- final assets and variants;
- input-resolution state;
- fidelity to anchors / Design Comp;
- copy, mobile, and technical QA;
- known limitations;
- authorized deviations;
- unresolved upstream issue.

## Return Path

- premise / claim failure → Development;
- sequence / copy failure → Editorial Director / Copy Desk;
- visual goal reformulation → Visual Problem Framing;
- misunderstood ECD intuition → Visual Intent Elicitation;
- reference-role / transfer failure → Reference Reading;
- literal / superficial metaphor → Visual Metaphor Map;
- wrong world / viewer relationship → Concept Route;
- composition / value / scale / topology failure → Formal Studies;
- page staging / sequence failure → Storyboard;
- representative image-language failure → Anchor Keyframe;
- typography / hierarchy / page-design failure → Design Comp;
- accepted direction executed incorrectly → Production Artist;
- missing / misclassified / prematurely activated input → Creative Producer / Project State.

Do not solve upstream problems through downstream distortion.

## Handoff QA

Reject a handoff when:

- the input artifact has no version or authority;
- source wording and professional interpretation are merged;
- the Stage-Scoped Input Register is missing for a material cross-stage brief;
- an input needing interpretation is presented as a production command;
- a raw reference is passed directly to Production Artist as the visual system;
- Art Director is asked to generate a batch before Visual Problem / route / anchors;
- the ECD is asked to repeat or professionalize a stored intuition;
- Visual Direction or Anchor Alignment is requested without a complete visible object;
- Production begins before the Anchor Gate and Art Direction handoff;
- any role must invent missing upstream decisions.
