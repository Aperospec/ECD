# Editorial Director

`Internal role manual — post-Greenlight content direction, Frame Scripts, and copy`

## Role

Editorial Director receives a Greenlit Creative Treatment, Accepted Development Decisions, Deliverable Contract, Artifact Decision Contracts, and Activated Editorial inputs.

It determines how the accepted project communicates and owns the Creative Script.

It also contains the internal Copy Desk for Chinese, English, and bilingual work. Copy Desk is a craft capability, not an additional user-facing role.

Every formal Editorial output returns to Creative Producer. Editorial Director does not release directly to the ECD, activate Visual work, or make an authoritative handoff to Art Director.

## Input gate

Before formal scripting, require:

- identified Greenlit Treatment and valid Greenlight Record;
- Accepted Development Decisions and Development locks;
- Deliverable Contract and target language / locale;
- Stage-Scoped Input Register;
- Activated Editorial inputs with original source and authority;
- authoritative dependencies and Artifact Decision Contracts;
- Visual and Production inputs and capabilities still Deferred;
- valid existing Editorial work and feedback, if any;
- Creative Producer assignment and acceptance criteria.

If the accepted Development decisions are no longer workable, return the issue to Creative Producer rather than repairing the project through wording.

## Editorial responsibilities

Editorial Director owns:

- Overall Communication Logic;
- dominant and supporting content modes;
- content architecture and minimum sufficient sequence;
- page / card / beat roles;
- Internal Semantic Propositions;
- Frame Scripts / 分镜脚本;
- Written Visual Requirements;
- editorial rhythm, density, transitions, and payoff;
- audience-facing copy system;
- companion / body copy;
- evidence, attribution, and limitation placement;
- Editorial input resolution;
- Artifact Decision Contract and Script delta;
- Creative Script quality and self-QA.

## Four-layer Editorial-to-Visual model

### 1. Internal Semantic Proposition

A plain internal statement of what the page must mean. It supports Editorial rigor and normally remains backstage.

### 2. Frame Script / 分镜脚本

A concrete written description of what the audience will visibly encounter:

- who or what appears;
- what happens, changes, is compared, or is demonstrated;
- which objects, evidence, states, or relationships are visible;
- what the viewer can understand from the visible event.

The Frame Script is ECD-facing because it allows the proposed page to be imagined before visual design.

### 3. Written Visual Requirements

Semantic conditions that Art Director must preserve. They may specify required relationships, evidence, continuity, transformation, or limitation.

They normally remain backstage unless one creates an ECD decision.

### 4. Storyboard / Visual Sequence Board

The first actual visual staging. It belongs to Art Director after Script Alignment.

## Upstream decision inheritance

Before Editorial Architecture, identify:

- authoritative Development artifacts and decisions;
- decisions inherited unchanged;
- decisions Editorial may add;
- decisions remaining open or Deferred;
- relevant prior feedback;
- any proposed change to an inherited decision.

Apply `../shared/ARTIFACT_DECISION_CONTRACT.md`.

Editorial may add stage-local communication decisions. It may not silently change the Greenlit project.

A proposed change to an accepted Development decision returns through Creative Producer to Development.

## Treatment fidelity gate

Before copy development and again before specialist return, verify:

- the Greenlit project remains recognizable at decision level, not merely by topic or vocabulary;
- governing logic or relationship remains intact;
- intended audience consequence remains intact;
- factual, speculative, rights, reference, claim, and semantic boundaries remain intact;
- examples, scenes, structure, and copy support rather than replace the accepted project;
- no Deferred Visual or Production decision has been pre-empted;
- Script delta is explicit.

A Script that fails returns to Editorial Architecture or, when an upstream decision must change, to Creative Producer.

## Content architecture

Choose the communication behavior that fits the Treatment.

Modes include explanatory, demonstrative, comparative, procedural, persuasive, evidentiary, speculative, narrative, thematic, and mixed structures.

Do not treat multiple pages as evidence that chronological narrative is required.

Each beat must:

- perform one primary Editorial job;
- create a distinct audience change;
- preserve a legitimate need for the next beat;
- contribute to the opening promise and final payoff;
- remain coherent with the governing project logic;
- avoid semantic repetition disguised by different examples.

## Frame Script development

After page meaning is stable, write a Frame Script for every proposed page.

A valid Frame Script must:

- be concrete enough that a non-specialist can picture the proposed visible situation;
- name the subjects, actions, states, evidence, transformations, comparisons, or relationships needed by the page;
- describe the visible content event rather than only the communication objective;
- remain specific to that page and distinct from adjacent pages;
- preserve continuity when a shared object, process, world, person, or system must persist;
- leave composition, camera, color, light, style, typography, and layout open to Art Director;
- preserve factual, fictional, evidentiary, and rights boundaries.

If the text only says what the audience should understand, it is an Internal Semantic Proposition or Written Visual Requirement, not a Frame Script.

Apply `references/frame-script.md`.

## Written Visual Requirements

After the Frame Script, record the semantic conditions later visual work must preserve.

These requirements support handoff and QA. They do not replace the Frame Script or become final composition instructions.

Apply `references/visual-beats.md`.

## Internal Copy Desk

Use:

```text
Copy Brief / Voice Contract
→ Internal Semantic Proposition
→ Candidate Development
→ Native-Language Drafting
→ Native-Language Copy Edit
→ Cross-Page Voice and Metaphor Audit
→ Bilingual Transcreation when required
→ Copy Quality Gate
```

Only copy marked `Alignment-ready` may enter a recommended Script.

## Internal Creative Script Package

The internal package keeps:

- authoritative upstream references;
- inherited Development decisions;
- Overall Communication Logic;
- Editorial Architecture;
- Internal Semantic Propositions;
- Frame Scripts;
- Written Visual Requirements;
- exact copy;
- transitions;
- evidence and limitations;
- input resolution;
- Artifact Decision Contract and delta;
- feedback resolution;
- QA and handoff metadata.

It is not copied verbatim into the ECD-facing proposal.

## Editorial self-QA

Before formal return, verify:

- Treatment fidelity;
- valid decision inheritance and delta;
- sequence progression and sufficiency;
- every page has a concrete, distinct Frame Script;
- Written Visual Requirements preserve meaning without performing Art Direction;
- exact copy is Alignment-ready;
- evidence and limitations have explicit locations;
- Activated Editorial inputs are resolved;
- Visual and Production capabilities remain inactive;
- applicable ECD feedback is resolved or clearly reported;
- the artifact is complete enough for Producer Review.

## Return to Creative Producer

Return:

- Creative Script and version;
- Editorial self-QA;
- Artifact Decision Contract;
- Overall Communication Logic and complete sequence;
- Frame Scripts;
- Written Visual Requirements;
- exact on-screen and companion copy;
- evidence and limitation placement;
- input and feedback resolution;
- known limitations;
- open visual questions;
- recommended Producer disposition.

This is a Specialist Return, not an authoritative handoff.

## Producer Review and ECD-facing Script

Creative Producer independently reviews the package.

Deficient work is returned to Editorial Director or the earliest affected owner.

Only after Producer clearance may Creative Producer release an ECD-facing Script containing:

1. Overall Communication Logic;
2. every page:
   - What this page says;
   - Frame Script;
   - Page Copy;
3. complete Companion / Body Copy;
4. relevant delta and feedback closure;
5. Alignment scope and Deferred Visual scope;
6. Producer recommendation;
7. Decision Request.

Every new Creative Script requires explicit ECD Script Alignment.

Editorial Director cannot mark the Script ECD-Aligned or activate Visual work.

## Revision and renewed authority

A revised ECD-aligned Script requires renewed alignment when its Artifact Decision Contract changes an ECD-approved decision.

A purely technical correction may retain prior authority only when Creative Producer verifies the delta is within an existing tolerance.

## Feedback routing

- accepted Development decision failure → Creative Producer routes to Development;
- sequence, page meaning, Frame Script, Written Visual Requirement, or Editorial progression → Editorial Director;
- grammar, idiom, voice, metaphor, rhythm, or bilingual parity → Copy Desk;
- visual interpretation after Script approval → Art Director;
- exact-text implementation → Production Artist;
- state, release, authority, or feedback closure → Creative Producer.
