# Creative Script Presentation

## Purpose

This protocol defines the ECD-facing presentation of a Creative Script before material Script Alignment.

The internal package may contain metadata, input IDs, detailed QA, and handoff records. The ECD-facing proposal is a complete, directly reviewable editorial object in the primary conversation.

## Mandatory visible order

1. **Script Core**
2. **Communication Strategy**
3. **Language and Copy Direction**
4. **Complete Page / Beat Sequence**
5. **Complete Companion / Body Copy**
6. **Treatment Fidelity, Sequence, and Copy QA**
7. **Script Alignment Scope**
8. **Decision Request**

## Script Core

Begin with one concise statement describing how the Script moves the audience from the opening condition to the final payoff.

## Communication Strategy

Present:

- dominant and supporting modes;
- opening promise;
- payoff;
- sequence logic;
- proposed page / beat count;
- why the structure is the minimum sufficient route.

## Language and Copy Direction

Present the target language / locale, voice, reader relationship, degree of compression, governing vocabulary or metaphor, and any material language choice that affects the ECD decision.

## Complete sequence

For every proposed page or beat, show:

```markdown
### Page / Beat [number] — [working label]

Function:
Editorial job:
Audience change:
Internal semantic proposition:
Written Visual Beat:
On-screen copy:
- title:
- optional deck:
- Core Line:
- supporting copy:
- evidence / source / limitation:
Must preserve:
Transition:
```

Omit only fields that genuinely do not apply. All material decisions remain visible.

A title list or sequence synopsis is not the complete decision object.

## Companion / Body Copy

Show the complete proposed copy in the primary conversation when the deliverable requires it.

## QA summary

State concisely:

- how the Script preserves the Greenlit Treatment;
- why adjacent beats perform distinct jobs;
- what material scenes, examples, or interpretations were introduced;
- how evidence and limitations remain intact;
- target-language Copy Quality Gate result;
- whether Activated Editorial inputs are resolved;
- confirmation that Visual and Production inputs remain Deferred.

If the Script fails professional quality, revise it before requesting alignment.

## Alignment scope

State exactly what the ECD is being asked to confirm, normally including:

- page count and order;
- communication progression;
- page roles and Written Visual Beats;
- exact on-screen copy;
- complete body copy;
- material invented examples or framing;
- evidence and limitation placement.

Then state the visual and production decisions that remain outside the current decision.

## Decision request

End with one explicit request: Script Alignment, revision, pause, or return to Development when the premise itself is wrong.

When alignment is required, downstream Visual activation remains pending until the response is recorded.

## Archive synchronization

The internal Script file and ECD-facing proposal must agree on all material editorial decisions and exact copy. Archive-only metadata may remain backstage.

## Presentation QA

Before requesting alignment confirm:

- the complete Script is visible in the primary conversation;
- no attachment is required to understand or judge it;
- every page has enough information to evaluate its distinct role;
- exact copy and complete body copy are visible;
- material new choices are disclosed;
- decision scope and Deferred visual scope are explicit;
- the response ends at the decision gate.
