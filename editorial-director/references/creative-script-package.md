# Creative Script Package

## Purpose

The Creative Script converts the Greenlit Treatment and Activated Editorial inputs into a complete communication blueprint for Art Director.

It resolves editorial meaning, concrete frame content, semantic visual requirements, and audience language while leaving final visual craft open.

The studio maintains two representations of the same accepted Script:

1. **Internal Creative Script Package** — technically complete for professional control and handoff.
2. **ECD-facing Creative Script Proposal** — decision-complete, concrete, and easy to judge without internal workflow knowledge.

The two representations must agree on all material content and exact audience copy.

## Input Gate

Require:

- Greenlit Treatment and valid Greenlight Record;
- Deliverable Contract;
- Stage-Scoped Input Register;
- Activated Editorial inputs with source and authority;
- target language and locale;
- Development locks and boundaries;
- Visual and Production inputs still Deferred;
- valid existing editorial work, if any.

## Internal Object Model

For each page, the internal package distinguishes:

- **Function / Editorial Job** — why the page exists;
- **Audience Change** — what becomes newly understood or felt;
- **Internal Semantic Proposition** — the exact meaning to preserve;
- **Frame Script** — what the audience will visibly encounter;
- **Written Visual Requirements** — semantic acceptance criteria for later visual work;
- **Page Copy** — exact audience-facing language;
- **Transition** — why the next page is needed;
- **Input Resolution and QA** — professional control records.

These fields are not automatically exposed to the ECD.

## Stage Boundary

The Script decides the proposed visible content through Frame Scripts and protects meaning through Written Visual Requirements.

It does not decide:

- final composition or placement;
- camera, lens, or crop;
- palette, light, material, or rendering style;
- typography, grid, spacing, or layout;
- final visual metaphor implementation;
- Storyboard panels;
- image-generation prompts;
- production rendering.

## Validation

The Script is ready for handoff when:

- the accepted project remains recognizable;
- Activated Editorial inputs are resolved;
- each beat advances;
- every page has a concrete Frame Script that passes the picture and multiplicity tests;
- Written Visual Requirements preserve meaning without performing Art Direction;
- exact audience copy is Alignment-ready;
- body copy is complete when required;
- evidence and limitations have explicit locations;
- material Script Alignment is resolved;
- later-stage inputs remain unexecuted;
- internal and ECD-facing representations agree;
- artifact state and dependencies are unambiguous.
