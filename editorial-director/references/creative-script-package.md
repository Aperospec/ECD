# Creative Script Package

## Purpose

The Creative Script Package is the Editorial Director's internal post-Greenlight artifact.

It converts the Greenlit Creative Treatment plus Activated Editorial projections into a complete communication blueprint for Art Director. It preserves state, source authority, sequence logic, Written Visual Beats, exact copy, input resolution, and handoff conditions.

The internal Package is not automatically the ECD-facing proposal. When Script Alignment is required, also apply `creative-script-presentation.md` and `../../shared/ECD_DECISION_PRESENTATION.md`.

## Input Gate

Before scripting, identify:

- Greenlit Creative Treatment and version;
- valid Greenlight Record;
- Deliverable Contract;
- Stage-Scoped Input Register;
- Activated Editorial input IDs, original source, and authority class;
- Deferred Visual / Art Direction and Production input IDs;
- complexity profile;
- factual, speculative, claim, rights, and reference boundaries;
- locked names, wording, evidence, limitations, and assets;
- valid existing editorial work.

Do not script when Greenlight is absent or not tied to the Treatment. Do not consume Deferred Visual inputs merely because they are visible in the raw brief.

## Choose the Smallest Sufficient Package

### Compact

Use for one to three screens or narrow editorial corrections. A concise table is acceptable, but it must preserve:

- Greenlit premise and audience takeaway;
- communication mode and sequence logic;
- complete page roles;
- Written Visual Beats;
- exact on-screen copy;
- companion copy when required;
- material limitations;
- Activated Editorial input resolution;
- Alignment state and Deferred visual scope.

Compact does not permit a summary-only ECD presentation.

### Standard

Use the normal template below, omitting fields that genuinely do not apply.

### Extended

Use all relevant fields, detailed evidence placement, claim boundaries, alternative compression, input-resolution records, and alignment records.

## Treatment Fidelity Rule

The Script may not silently change the Greenlit governing mechanism.

Examples of material drift include:

- replacing retrospective sharing and reinterpretation with real-time task assistance;
- replacing a personal memory concept with a product-use-case list;
- claiming a complete life record where the Treatment preserves fragments and gaps;
- changing the role of AI, the person, or the archive;
- substituting a new public position because it is easier to structure.

Return a material premise problem through Creative Producer. Do not hide it inside wording.

## Page Progression Rule

Every beat must create a distinct audience change.

Different objects, activities, or settings do not establish distinct beats when each page repeats the same mechanism. Merge, remove, or redefine such pages before the Script is submitted.

## Copy Completeness Rule

Art Director must not need to invent a headline, shorten a claim, remove a limitation, or write companion copy to make the design work.

Exact proposed on-screen copy and complete companion copy must exist before handoff.

## Stage Boundary Rule

The Script may carry semantic visual requirements through Written Visual Beats, but it must not activate or resolve:

- reference palette extraction;
- lighting system;
- camera / lens / framing strategy;
- detailed composition;
- typography personality;
- visual-world finish;
- Storyboard panels;
- production rendering.

## ECD-Facing Presentation Rule

When Script Alignment is material, the complete ECD-facing Creative Script Proposal must be presented in the primary conversation before the decision request.

A page-title list, short synopsis, or attachment link is not the decision object.

The primary conversation must contain:

- Script Core;
- Communication Strategy;
- complete sequence with every page's function, Editorial Job, Audience Change, Written Visual Beat, exact copy, preservation / limitation rule, and transition when relevant;
- complete companion / body copy;
- fidelity and sequence QA;
- exact Alignment scope;
- Deferred visual scope;
- explicit decision request.

The archive Package may contain additional IDs and state detail, but may not hide unique material decision content.

## Validation Rules

The Package is ready for ECD-facing presentation only when:

- Greenlight is valid;
- the Treatment's creative core and governing mechanism remain intact;
- Activated Editorial inputs are identifiable and resolved;
- sequence progression is coherent and non-repetitive;
- Written Visual Beats are semantic and visually open;
- exact audience-facing copy is complete;
- complete companion copy exists when required;
- material new examples / fictional content are disclosed;
- evidence and limitations have explicit locations;
- Deferred Visual / Production inputs remain unexecuted;
- the ECD-facing proposal is complete without attachment dependency;
- Alignment scope is unambiguous.

The Package may be marked Accepted for Handoff only after any required ECD Script Alignment is validly recorded against the complete visible proposal.
