# Creative Script Package

## Purpose

The Creative Script is Editorial Director's formal post-Greenlight artifact.

It converts the Greenlit Creative Treatment plus Activated Editorial projections into a complete audience-facing communication blueprint for Art Director.

The package must resolve both:

1. **editorial architecture** — what each page does and how the sequence advances;
2. **copy craft** — how that meaning becomes natural, precise, Alignment-ready Chinese, English, or bilingual copy.

A field-complete Script containing first-draft wording is not complete.

## Input Gate

Before scripting, identify:

- Greenlit Creative Treatment and version;
- valid Greenlight Record;
- Deliverable Contract;
- target language and locale;
- Stage-Scoped Input Register reference;
- Activated Editorial input IDs, original source, and authority class;
- Deferred Visual / Art Direction and Production input IDs;
- complexity profile;
- factual, speculative, claim, rights, and reference boundaries;
- locked names, wording, evidence, limitations, and assets;
- valid existing sequence or copy work.

If the premise is materially broken, return through Creative Producer and reopen Development.

If Greenlight is absent or invalid, do not script.

Do not consume Deferred Visual input merely because it is visible in the raw brief.

Apply:

- `copy-desk-workflow.md`;
- `social-editorial-copy.md`;
- `chinese-copy-craft.md` or `english-copy-craft.md`;
- `bilingual-transcreation.md` when required;

## Copy Status

Record one status:

- `Semantic Draft`;
- `Candidate Drafts`;
- `Selected Draft`;
- `Copyedited`;
- `Alignment-ready`;
- `Reopened`.

Only `Alignment-ready` copy may be presented as the recommended final wording in a Script Alignment request.

## Copy Completeness Rule

Art Director should not have to:

- invent a headline;
- correct grammar or collocation;
- decide what an unclear pronoun means;
- rewrite translated English or Chinese;
- remove a limitation;
- reconcile two metaphor systems;
- write companion copy;
- choose among unedited first drafts.

When visual layout exposes a genuine copy problem, return it to Editorial Director through Creative Producer.

## Stage Boundary Rule

The Creative Script resolves Editorial and Copy Desk questions only.

A Script may carry semantic visual requirements through Written Visual Beats, but it must not activate or resolve:

- reference palette extraction;
- lighting system;
- camera / lens / framing strategy;
- detailed composition;
- typography personality;
- visual-world finish;
- production rendering.

## Alignment-Readiness Rules

The Script is ready for ECD-facing presentation only when:

- authoritative Treatment and deliverable are identifiable;
- Greenlight is valid;
- Activated Editorial inputs are resolved;
- Treatment Fidelity passes;
- sequence progression is coherent;
- Written Visual Beats are original, semantic, and visually open;
- all audience-facing copy exists in every required language;
- target languages and locales are identified;
- every high-impact line has received a native-language copy edit;
- bilingual versions pass independently and as a pair when required;
- exact and compressible wording are distinguished;
- evidence and limitations have explicit locations;
- Copy Quality Gate passes with no hard failure;
- any material ECD Script choice is recorded;
- Deferred Visual / Production inputs remain unexecuted;
- artifact and copy states are unambiguous.

Apply `creative-script-presentation.md` before requesting Script Alignment.
