# Content Modes

## Purpose

Content Mode defines the dominant communication behavior of a Social Editorial piece or section.

Do not treat narrative as the default. Select the mode that best serves the Greenlit Creative Treatment and Accepted Development Decisions.

## Core modes

### Narrative

Use when meaning depends on change over time, lived experience, tension, or a sequence of events.

Primary question:

> What happens, changes, or is experienced?

### Explanatory

Use when the audience needs to understand a concept, mechanism, relationship, or cause.

Primary question:

> How does this work, and why?

### Demonstrative

Use when value lies in showing a capability, transformation, output, or observable behavior.

Primary question:

> What can we actually see happening?

### Comparative

Use when meaning emerges through a relevant difference between states, methods, objects, or outcomes.

Primary question:

> What changes when A is compared with B?

### Procedural

Use when the audience needs to understand a process, workflow, or ordered action.

Primary question:

> What happens step by step?

### Persuasive / Argumentative

Use when the piece advances a judgment or interpretation that must be supported.

Primary question:

> Why should the audience accept or reconsider this claim?

### Evidentiary

Use when screenshots, tests, outputs, documents, data, or observed results should carry the main Editorial weight.

Primary question:

> What evidence makes this visible or credible?

### Speculative

Use for future-facing concepts, hypothetical states, conceptual worlds, or imaginative propositions.

Primary question:

> What becomes thinkable if this premise is allowed to unfold?

Speculative mode must preserve the distinction between imagination and current fact.

### Thematic / Associative

Use when meaning emerges through related facets, motifs, memories, perspectives, or conceptual associations rather than chronology or a single causal chain.

Primary question:

> What larger understanding emerges when these distinct facets are held together?

Thematic structure still requires progression. It is not permission to stack interchangeable examples.

## Mixed mode

Most strong pieces use a dominant mode plus one or two supporting modes.

Examples:

- Explanatory + Demonstrative
- Speculative + Narrative
- Comparative + Evidentiary
- Persuasive + Explanatory
- Procedural + Demonstrative
- Thematic + Reflective explanation

Do not switch modes merely for variety. A mode change should correspond to a change in Editorial job.

## Mode selection

Choose by asking:

1. What cognitive or emotional movement does the audience need?
2. What kind of proof or progression does the Treatment require?
3. Is the value in understanding, seeing, comparing, following, imagining, associating, or being persuaded?
4. Which mode would distort the accepted project if overused?
5. Does the proposed structure preserve the governing logic or merely reuse the same topic vocabulary?

## Anti-patterns

Avoid:

- treating multiple pages as automatic evidence for chronological narrative;
- forcing a simple demonstration into dramatic storytelling;
- forcing a speculative concept into current-feasibility analysis;
- turning an explanation into a tutorial when no action is required;
- turning every evidence page into a comparison;
- using emotional narrative to conceal weak evidence;
- using a list when the audience needs causal progression;
- using thematic structure as a collection of repetitive examples;
- changing the accepted project mechanism because another mode is easier to write.

## Output use

Record:

- dominant mode;
- supporting modes;
- Overall Communication Logic;
- mode changes that correspond to real Editorial changes;
- modes deliberately rejected because they would distort the accepted project.

Mode is a communication decision, not a visual style.
