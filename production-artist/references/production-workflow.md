# Production Workflow

## Purpose

This workflow turns an Art Direction Package Accepted for Handoff plus Activated Production inputs into final Social Editorial assets without allowing technical convenience, raw references, or generation defaults to redefine the work.

Production Artist owns exact realization, deterministic typography, variants, export, and technical finish. It does not own the premise, Script meaning, visual problem, reference interpretation, metaphor, Concept Route, or ECD alignment.

## Stage 0 — Production Authorization Gate

Do not begin broad production until all relevant inputs are identifiable:

- Deliverable Contract;
- Stage-Scoped Input Register;
- Activated Production inputs and authority classes;
- Creative Script Accepted for Handoff;
- selected / accepted Concept Route;
- Visual Direction Alignment record when required;
- Storyboard / Visual Sequence Board;
- Anchor Keyframe Gate passed or valid bypass recorded;
- accepted World / Cover Anchor and Representative Body Anchor when applicable;
- Representative Design Comp or explicit reason it is unnecessary;
- Anchor / Design Alignment record when required;
- Color Script / sequence system when material;
- Art Direction Package Accepted for Handoff;
- exact audience-facing copy;
- assets, provenance, permissions, dimensions, variants, and tolerances.

Return to Creative Producer when:

- Production inputs remain Deferred;
- Art Direction Package is not Accepted for Handoff;
- Anchor Gate is missing;
- required visual alignment is unresolved;
- the only governing visual input is a raw reference;
- execution would require inventing or repairing the visual system.

## Stage 1 — Authority and Input Review

Record:

```markdown
| Input / artifact | Authority | Production consequence | Conflict / risk | Planned resolution |
|---|---|---|---|---|
```

Confirm:

- Hard Constraints are feasible or escalated;
- User Preferences are distinguished from locks;
- ECD Aesthetic Judgments have accepted professional translations;
- Assistant Inference is not treated as user authority;
- reference principles and prohibited transfer are explicit;
- every requested variant and platform condition is visible.

## Stage 2 — Anchor and World Translation

Before generating additional images, build a production-facing continuity summary from accepted visual artifacts:

```markdown

Dominant scale relationship:

```

Production prompts and briefs derive from this summary, the relevant Storyboard panel, and Art Direction Package—not directly from the raw reference.

## Stage 3 — Asset Inventory

```markdown
| Asset | Source / owner | Role | Transformation | Permission / attribution | Resolution | State | Risk |
|---|---|---|---|---|---|---|---|
```

Classify assets as:

- supplied and locked;
- supplied and transformable;
- accepted anchor-derived;
- authentic evidence;
- to be generated;
- to be edited or cleaned;
- to be sourced or captured;
- to be constructed deterministically;
- fallback only.

Do not replace evidence with fictional imagery or copy a reference because it is easier to generate.

## Stage 4 — Screen Implementation Plan

For each screen define:

- Script beat and Storyboard source;
- anchor / Design Comp relationship;
- Activated Production inputs served;
- target dimensions and safe areas;
- background / environment layer;
- hero / evidence layer;
- foreground and depth layers;
- world-continuity rules;
- subject–environment scale;
- value and color state;
- typography / graphic-structure layer;
- masks and overlap;
- deterministic text blocks and line breaks;
- crop / variant behavior;
- risk and fallback.

Preserve editable separation between imagery, typography, masks, and evidence whenever possible.

## Stage 5 — Image and Asset Realization

### Original imagery

When generating imagery:

- use the accepted Art Direction Package, relevant Storyboard panel, anchors, and Color Script;
- generate without final publication text by default;
- preserve required world rules, spatial hierarchy, and depth planes;
- keep characters in the accepted role and scale;
- verify subject identity, count, pose, action, object state, and physical relationships;
- reject malformed geometry, impossible contact, inconsistent perspective, or accidental flatness;
- reject drift into prohibited genres such as tourism advertising, generic game key art, sentimental film still, cold institution, or theme-park poster when those are forbidden;
- maintain sufficient resolution for crop and export.

### Anchor continuity

For every generated screen, compare:

- dominant silhouette;
- world topology;
- scale;
- material;
- value;
- light-source logic;
- atmospheric depth;
- reference distance;
- subject–environment hierarchy;
- emotional distance.

A visually attractive screen that no longer belongs to the accepted world fails.

### Supplied image editing

- preserve elements the ECD intends to keep;
- prefer localized editing over unnecessary global regeneration;
- retain product, interface, face, object, or evidence fidelity as required;
- document reconstruction or simulation;
- do not replace a real screenshot with fictional UI.

### Evidence assets

- preserve evidence itself;
- retain source, date, version, labels, region, and limitations when material;
- annotate without covering critical details;
- distinguish observed output, source claim, simulation, and reconstruction.

### Masks, edges, contact, and depth

Check:

- final-size edges;
- transparent and thin geometry;
- contact shadow and grounding;
- overlap order and occlusion;
- consistent light direction;
- volume and perspective;
- no sticker-like halo unless intentional.

## Stage 6 — Batch Control

Broad production follows an accepted anchor system.

Do not use batch generation to discover:

- the visual problem;
- the reference role;
- the metaphor;
- the world logic;
- character / environment priority;
- the visual route.

When repeated generations drift in the same conceptual way, stop. Return to Art Director instead of increasing batch size.

A failed batch does not become useful merely because one frame has attractive detail.

## Stage 7 — Deterministic Typography

Compose final audience-facing text in a deterministic renderer whenever exact text matters.

Control:

- Unicode text and punctuation;
- language glyph coverage;
- accepted font or fallback;
- size, weight, width, tracking, leading, and alignment;
- semantic line breaks;
- wrapping and overflow;
- masks and type–image depth;
- source, caption, and limitation hierarchy;
- repeatability across variants.

Compare every line against the Accepted Creative Script.

Production Artist may not rewrite weak Chinese or English for convenience. Return copy defects to Copy Desk.

## Stage 8 — Layout Assembly

Assemble against accepted Design Comp and Art Direction Package.

Check:

- first-, second-, and third-glance hierarchy;
- world / hero recognition;
- center of gravity and reading path;
- title scale and confidence;
- image–type overlap;
- grid, margin, and negative space;
- body-page density;
- evidence visibility;
- safe areas and platform overlays;
- anchor continuity;
- Color Script position;
- cross-page shared grammar and intentional variation.

A layout is not complete merely because every element fits.

## Stage 9 — Fit and Overflow Repair

Use the smallest authorized change:

1. accepted line breaks and widths;
2. accepted alternate copy compression;
3. spacing or geometry inside tolerances;
4. accepted font fallback;
5. return to Art Director for hierarchy / composition / image-world change;
6. return to Editorial Director for wording change.

Forbidden repairs:

- hiding or clipping text;
- shrinking required copy to decorative size;
- removing qualifications;
- covering evidence;
- generic text boxes without Art Direction support;
- flattening or shrinking the world / hero relationship;
- changing title or copy for ease;
- violating reference or visual Hard Constraints.

## Stage 10 — Variants and Surface Adaptation

For each variant:

- begin from the accepted visual premise, not a blind crop;
- preserve hierarchy, world, and meaning;
- re-evaluate safe areas and UI overlays;
- adapt composition when aspect ratio changes relationships;
- return to Art Director when adaptation becomes redesign;
- verify exact copy and evidence independently.

## Stage 11 — Visual, Mobile, and Technical QA

Run `mobile-qa.md` plus:

- Brief / Script fidelity;
- Concept Route fidelity;
- anchor fidelity;
- world coherence;
- reference-distance check;
- metaphor fidelity;
- Color Script progression;
- subject–environment hierarchy;
- sequence differentiation;
- exact-copy and glyph integrity;
- file, dimension, crop, and export integrity.

Critical failures block delivery:

- primary meaning or copy unreadable;
- required evidence / limitation hidden;
- invalid files or dimensions;
- unauthorized reference use;
- drift from accepted anchors or Design Comp;
- world-led concept replaced by isolated generic scenes;
- unaccepted change to Script meaning;
- silent omission of a Hard Constraint.

## Completion Standard

Production is complete only when:

- every requested asset and variant exists;
- all Activated Production inputs have a resolution state;
- accepted route, anchors, Design Comp, and Color Script survive;
- exact copy is correct;
- files pass mobile and technical QA;
- evidence, limitations, and attribution remain visible;
- user Hard Constraints were not dropped;
- unauthorized deviations are absent;
- known limitations are recorded.
