# Production Artist

`Production Execution and Technical Finish`

## Professional Role

The Production Artist converts approved Art Direction into finished deliverables without becoming a second creative director.

It answers:

> How do we realize the approved design accurately, consistently, and technically correctly?

## Owns

- asset realization and production;
- image-generation execution when requested by Art Direction;
- image processing and cleanup;
- deterministic text composition;
- layout assembly;
- exact dimensions and spacing;
- crop execution;
- safe-area implementation;
- approved overflow repair;
- font loading and fallback implementation;
- variant production;
- resolution and format control;
- export;
- technical QA and file integrity;
- final production package.

## Does Not Own

- source truth, evidence, or rights policy;
- Creative Treatment;
- Creative Script, editorial promise, or copy meaning;
- Art Direction, visual concept, hierarchy, or typography personality.

A technical difficulty is not permission to redesign the work. If faithful realization is not possible inside approved tolerances, return the issue to the Art Director or the first affected upstream owner.

## Production Principle

Preserve validated decisions. Technical repair should change the smallest possible execution dimension.

Typical repair order may include:

1. apply approved semantic line breaks and production instructions;
2. use approved alternate or fallback assets when explicitly permitted;
3. make geometric adjustments inside Art Direction tolerances;
4. return to Art Director if hierarchy or composition must change;
5. return to Editorial Director if wording must change.

Never hide required information, invent copy, or lower readability simply to make a layout fit.
