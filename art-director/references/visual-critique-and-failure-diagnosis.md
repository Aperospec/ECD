# Visual Critique and Failure Diagnosis

## Purpose

This protocol converts visual approval, discomfort, or rejection into a professional diagnosis and the smallest valid rework route.

## Critique sequence

```text
Description
→ Formal Analysis
→ Interpretation
→ Evaluation against accepted objects
→ Earliest-failed-object diagnosis
→ Rework recommendation
```

Keep visible observation separate from interpretation and evaluation.

## Evaluation dimensions

### Brief fidelity

Does the work solve the accepted Visual Problem Statement and preserve the project and Script?

### Intent fidelity

Does the work reflect the ECD's recorded visual priorities and authority classes?

### Reference fidelity and distance

Are assigned reference roles used correctly? Are transferred principles present without replacing the project with source-specific expression?

### Metaphor fidelity

Does the metaphor generate meaningful relations and behavior, or has it become surface resemblance?

### Concept-route coherence

Does the work preserve the selected viewer relationship, world / scene / information logic, and dominant hierarchy?

### Formal quality

Review composition, silhouette, value, scale, depth, salience, movement, rhythm, color, light, negative space, and copy relationship.

### Sequence coherence

Review page-to-page progression, shared grammar, purposeful variation, and the relationship between opening promise and payoff.

### Representative-proof fidelity

Does the work remain consistent with accepted anchors and Design Comp?

### Production quality

Review anatomy or geometry, perspective, contact, material, lighting, masks, text, crop, resolution, consistency, and export.

## Earliest-failed-object routing

| Earliest failed object | Owner |
|---|---|
| Visual Problem Statement | Art Director |
| Visual Intent record | Creative Producer + Art Director |
| Reference Reading / Transfer | Art Director |
| Visual Metaphor Map | Art Director |
| Concept Route | Art Director |
| Formal Studies | Art Director |
| Storyboard / Visual Sequence Board | Art Director |
| Anchor Keyframe | Art Director |
| Representative Design Comp | Art Director |
| Accepted direction executed incorrectly | Production Artist |
| Script meaning or copy caused the visual defect | Editorial Director / Copy Desk |

## Rejection protocol

When the ECD rejects visual work:

1. stop dependent broad production;
2. record the source feedback without rewriting it;
3. compare the work with the accepted project, Script, route, reference transfer, anchors, and Design Comp;
4. identify the dominant failure dimensions;
5. state the diagnosis in plain language;
6. identify the earliest failed object;
7. preserve unaffected decisions;
8. create a lower-cost diagnostic proof before broad work resumes.

## Quality gate

A diagnosis is ready when:

- it addresses the actual accepted project;
- visible causes are distinguished from subjective preference;
- the earliest failed object is identified;
- rework is no broader than necessary;
- the next proof is cheaper and more diagnostic than another broad production pass;
- the ECD can understand the conclusion without specialist vocabulary.
