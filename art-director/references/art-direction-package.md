# Art Direction Package

## Purpose

The Art Direction Package is Art Director's formal handoff to Production Artist.

It converts an accepted Creative Script, resolved Storyboard / Visual Sequence Board, and accepted Representative Design Comp into an executable visual system. Production Artist should not need to invent creative logic.

## Input Gate

Before final Art Direction, identify:

- Greenlit Creative Treatment and accepted Creative Script;
- Deliverable Contract and target viewing conditions;
- written Visual Beats and final / approved copy;
- Storyboard / Visual Sequence Board state;
- Representative Design Comp state or explicit reason it is unnecessary;
- ECD visual alignment state;
- reference, rights, evidence, and asset boundaries;
- locked decisions and open variables.

Do not use a text-only Art Direction Package to conceal an unresolved hierarchy, typography, image–type relationship, or mobile-readability problem that should have been proven in a Comp.

## Boundary Rule

Art Direction may reinterpret **how** a written Visual Beat is shown. It may not rewrite **what** the beat means.

If the design only works by changing sequence, copy meaning, evidence, required limitation, or Greenlit premise, return the problem through Creative Producer to the first affected owner.
