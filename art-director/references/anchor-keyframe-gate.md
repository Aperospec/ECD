# Anchor Keyframe Gate

## Purpose

The Anchor Keyframe Gate prevents a new visual system from being expanded into a full image set before its world, metaphor, composition, and image language have been proven.

For a materially new, reference-led, metaphor-led, or world-led project, broad production must not begin from prose alone, from a mood board alone, or from one untested generation prompt.

## Core Rule

> Prove the visual system with the smallest representative set before producing the batch.

Normally use:

1. **World / Cover Anchor** — proves the governing world, first-glance promise, scale, and visual thesis.
2. **Representative Body Anchor** — proves how a specific Script beat exists inside the same world without becoming a generic standalone illustration.

Add a third anchor only when a materially different page class cannot be inferred, such as a dense evidence page, comparison, diagram, or radically different closing frame.

## Relationship to Other Artifacts

### Concept Route

Chooses the governing visual system.

### Storyboard / Visual Sequence Board

Stages every beat at low cost and tests sequence coherence.

### Anchor Keyframe

Proves the image world and representative scene language at meaningful fidelity.

### Representative Design Comp

Combines credible imagery with real copy, typography, layout, geometry, and mobile viewing conditions.

An Anchor Keyframe may become the image basis of a Design Comp. The objects may be combined for Compact work when one high-fidelity proof resolves both image-world and page-design questions.

## Required Inputs

- selected / aligned Concept Route;
- Visual Problem Statement;
- Reference Reading and Transfer Record;
- Visual Metaphor Map when applicable;
- Storyboard or sufficiently resolved sequence studies;
- target geometry and viewing condition;
- accepted copy for any Design Comp combination;
- ECD decisions and visual hard constraints.

## World / Cover Anchor Tests

Confirm:

- the project-specific world is visible before decorative detail;
- the establishing view communicates the governing visual idea;
- the reference has been transformed rather than reproduced;
- subject scale supports the Script;
- the image does not read primarily as tourism advertising, generic game key art, a commercial theme-park poster, or another unauthorized genre;
- the world has enough logic to support later pages;
- the image retains usable territory for copy or a planned type–image relationship.

## Representative Body Anchor Tests

Confirm:

- the selected beat remains semantically distinct;
- the frame belongs unmistakably to the same world;
- the environment still carries concept, not only background atmosphere;
- people and emotion do not erase the governing spatial or conceptual logic;
- the frame avoids becoming a generic film still;
- scale, material, light, and world rules remain continuous;
- the frame can support the intended page hierarchy and copy density.

## ECD-facing Anchor Alignment

Show the actual anchor proofs in the primary conversation.

Present in plain language:

- what each image is proving;
- what was taken from the reference at the level of principle;
- what was intentionally not copied;
- how the two images belong to one visual system;
- the principal remaining risk;
- what will become locked;
- what remains open for the rest of the sequence.

The ECD should not need to inspect image-generation prompts or technical rendering notes.

## Anchor-before-Batch Prohibition

Before the Anchor Gate passes, do not:

- generate four to eight final-looking deliverable images;
- render the whole carousel at high fidelity;
- create multiple cosmetic variations and ask the ECD to pick one;
- call a montage of unaligned scenes a visual system;
- activate Production Artist for broad asset creation;
- use the existence of expensive generations as pressure to accept the direction.

A maximum of two representative high-fidelity image anchors is the default pre-alignment set. A third requires a recorded distinct page-class reason.

Low-fidelity thumbnails, value studies, and concept-route experiments are not counted as broad production when clearly labeled exploratory.

## Bypass Conditions

The Anchor Gate may be compressed or bypassed only when:

- the task is a narrow correction inside an already accepted visual system;
- an existing accepted key visual and body system are valid for the requested work;
- the user supplied an explicitly accepted professional visual artifact whose authority can be verified;
- the project is purely typographic / information-design work and the Representative Design Comp alone resolves all material visual risk.

Record the reason. “The project is small” or “the model can generate all images quickly” is not a valid bypass.

## Rejection and Revision

If an anchor fails:

1. diagnose the first failed visual object;
2. do not automatically produce another batch;
3. reopen the Concept Route, Reference Reading, Metaphor Map, Storyboard, or formal study where the defect first appears;
4. preserve unaffected work;
5. produce a revised anchor only after the underlying decision changes.

## Production Activation

Production may begin only after:

- the selected visual route is accepted;
- required Visual Direction Alignment is recorded;
- Anchor Keyframe Gate passes;
- Representative Design Comp passes when typography / layout is material;
- Art Direction Package identifies how the system extends to every screen;
- Creative Producer explicitly activates Production inputs.
