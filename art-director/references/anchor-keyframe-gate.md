# Anchor Keyframe Gate

## Purpose

The Anchor Keyframe Gate proves a new visual system with the smallest representative set before broad Production.

Anchors are Art Director artifacts. They require visual self-QA and Producer Review before ECD release or downstream authority.

## Core rule

A new, reference-led, metaphor-led, world-led, or otherwise unresolved multi-image visual system normally requires:

1. **World / Cover Anchor** — proves governing visual system, first-glance promise, scale, and viewer relationship.
2. **Representative Body Anchor** — proves how a specific Script beat exists within the same system.
3. **Additional Anchor** — only when a different page class cannot be inferred from the first two.

The proof burden scales with visual novelty, copy–image interdependence, and risk, not an arbitrary page count.

## Exploratory study versus Production-intent Anchor

### Exploratory Image-World Study

May test atmosphere, light, material, world logic, subject language, or reference transfer before exact copy geometry is resolved.

It must be marked `Exploratory`. It is not an Anchor eligible for direct final-page reuse and cannot be silently promoted because it is visually successful.

### Production-intent Anchor

Is generated, selected, edited, or cropped with a reasonable expectation that it may inform or enter a final screen.

It requires a Copy-Aware Layout Map before creation or commitment.

The map must use exact copy and define provisional line behavior, copy footprint, protected visual content, image–type relationship, local contrast, crop latitude, and generation consequences.

Apply `copy-aware-composition.md`.

## Relationship to other artifacts

- Concept Route establishes governing visual logic.
- Storyboard stages the sequence at low cost and identifies copy-aware spatial needs.
- Copy-Aware Layout Map converts exact copy into visual and image-generation constraints.
- Anchor Keyframes prove representative image-world language within those constraints.
- Representative Design Comp proves actual typography, hierarchy, geometry, Type-Fit, and mobile behavior.

Compact work may combine proof objects when one artifact genuinely resolves all required questions. Authority and Producer Review remain distinct.

## Required inputs

- ECD-aligned Script, accepted Frame Scripts, and exact copy;
- selected Concept Route;
- Visual Problem Statement;
- Visual Intent record;
- Reference Reading / Transfer;
- Visual Metaphor Map when applicable;
- formal studies;
- Storyboard or sufficiently resolved staging;
- target geometry and viewing condition;
- Artifact Decision Contracts and active locks;
- Copy-Aware Layout Map for every Production-intent Anchor;
- Creative Producer assignment and proof question.

## Anchor review criteria

Each Anchor must prove:

- fidelity to accepted route and upstream decisions;
- correct first-glance meaning;
- coherent large shapes and value structure;
- intended subject–environment or evidence hierarchy;
- correct reference transfer and sufficient originality;
- consistency with the sequence;
- viability at target geometry;
- ability to generate further pages without changing the governing system.

Each Production-intent Anchor must additionally prove:

- fidelity to its Copy-Aware Layout Map;
- preservation of text footprint, protected zones, and local contrast;
- sufficient crop and extension latitude;
- absence of uncontrolled required audience text;
- plausible deterministic typography and Type-Fit in a Design Comp.

The representative body Anchor additionally proves that a specific beat does not collapse into a generic standalone illustration or unrelated page system.

## Producer Review and gate effect

Creative Producer independently verifies image class, proof, Layout Map fidelity, delta, feedback closure, and decision readiness.

Before Producer clearance and required ECD Visual Alignment, visual output remains limited to studies and representative proof.

After required authority:

- Art Director may complete Design Comp, color / sequence system, and Art Direction Package;
- exploratory assets remain exploratory unless separately cleared through Copy-Aware Composition;
- broad Production still requires Producer Cleared Art Direction and explicit Production activation.

## Failure recovery

When an Anchor fails:

1. identify whether the cause is upstream fidelity, copy hierarchy, Layout Map, visual problem, intent, reference, metaphor, route, formal study, staging, or the image asset itself;
2. return through Creative Producer;
3. preserve unaffected decisions;
4. revise the minimum representative proof;
5. rerun Art Director self-QA and Producer Review;
6. obtain required visual authority before expansion.
