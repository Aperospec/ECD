# Minimum Professional Chain Evals — V3.1

## Purpose

Verify that V3 is not merely a department diagram. Every required capability must create a real artifact, and each Director must review it before Producer integration.

## Development chain

Required evidence:

1. Creative Strategy Return with alternatives or a reason the angle is fixed;
2. Concept Development Return with governing logic and stress test;
3. Research Verification Return when external facts or current claims matter;
4. Claims Rights Return when third-party source use or conceptual demonstration matters;
5. Development Review Record based on actual artifacts;
6. Department Cleared Treatment Package.

Failure:

- Treatment appears with no specialist evidence;
- Director claims a review that did not occur;
- downstream copy or design is embedded in Development.

## Editorial chain

Required evidence:

1. Content Architecture Return;
2. Frame Script Return for every page or beat;
3. Copywriting Return with explicit speaker / reality position;
4. Copy Editing Return that inspects the completed draft;
5. Proofreading Return with clean exact text;
6. Editorial Review Record;
7. Department Cleared Creative Script Package.

Failure:

- one model draft is relabelled as architecture, writing, editing, and proofing without distinct method evidence;
- false or misleading first-person experience survives Copy Editing;
- Visual decisions appear before Script Alignment.

## Visual chain

Required evidence:

1. Visual Concept Return;
2. Storyboard / Sequence Return for multi-page work;
3. Editorial Design Return and METHOD evidence;
4. Typography Return and METHOD evidence;
5. Image Direction Return when imagery is required;
6. separate Design Critique Return on actual artifacts;
7. Art Director Review Record;
8. full-sequence coverage and representative fidelity proof;
9. Department Cleared Visual Package.

Failure:

- one polished image stands in for design;
- exact copy is absent from representative proof;
- Critique is only a score or self-praise;
- all pages repeat one template;
- Art Director clears based on descriptions rather than artifacts.

## Production chain

Required evidence:

1. Image Production Return when final imagery is required;
2. Finished Art Return;
3. Production Typesetting Return;
4. Technical QA Return based on opened exports;
5. Production Director Review Record;
6. Editorial and Visual final sign-offs;
7. Department Cleared Final Production Package;
8. Producer Final Review.

Failure:

- generated text is accepted as exact final copy;
- exported files are not opened and inspected;
- copy or design is silently changed for fit;
- Final Acceptance is requested without direct previews and sign-offs.

## Registration audit

For every `Implemented` entry in `core/CAPABILITY_REGISTRY.md` verify:

- file exists;
- frontmatter contains unique `name`;
- frontmatter contains usable `description`;
- Skill appears in installation feedback or runtime discovery;
- Director references the exact registered name;
- a sample task can produce the defined Specialist Return.

V3 is not ready for project testing until the registration audit passes.
