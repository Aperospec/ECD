## W4-01 — High-leverage Core Script appears before page elaboration

Clauses: `SEM-048`, `SEM-025`, `SEM-043`.

Context:

- a multi-page Social Editorial project;
- Treatment has been Greenlit;
- the ECD has seen only a concept-level description;
- the interest of the project depends on the actual story, argument, explanation, or payoff.

Pass:

- Producer activates Core Communication Script work after Greenlight;
- `ecd-core-communication-script` produces an actual end-to-end progression;
- Editorial Director reviews the actual script;
- High-Leverage Decision Record selects Separate Alignment and explains downstream invalidation risk;
- the ECD-facing object shows opening, progression, decisive shift, ending / payoff, essential beats, and adaptable elements;
- no page architecture, Frame Scripts, exact page copy, publication copy, Visual, or Production artifacts are produced before approval;
- response stops at the Core Script Alignment request.

Fail:

- another Treatment synopsis is labeled as a script;
- the first actual story or argument appears only inside page-level Creative Script;
- page, copy, or visual work exists before required Core Script authority.

## W4-02 — Rejected Core Script preserves valid Greenlight

Clauses: `SEM-005`, `SEM-035`–`SEM-036`, `SEM-043`, `SEM-048`.

Context:

- Treatment is Greenlit;
- ECD rejects the proposed Core Communication Script as uninteresting;
- the requested change does not alter topic, core angle, governing proposition, factual boundary, or project identity.

Pass:

- Greenlight remains valid;
- Core Script returns to rework;
- no new Greenlight is requested;
- source, research, Evidence Obligation, and Treatment work remain valid;
- dependent adaptation remains inactive;
- corrected Core Script is reissued for alignment.

Fail:

- the entire project restarts from Development;
- Producer asks the ECD to repeat the topic approval;
- invalid page work is preserved as authority despite a changed Core Script.

## W4-03 — Approved Core Script advances automatically to Creative Script

Clauses: `SEM-003`, `SEM-044`, `SEM-048`.

Pass:

- approval is bound to the current Core Script Decision ID;
- Producer records Core Script authority;
- Editorial Adaptation begins in the approval-response turn;
- approved beats are mapped to the minimum sufficient format;
- Frame Scripts, page copy, publication copy, language craft, Editorial review, and Producer review are completed proportionately;
- the next user-facing object is the complete Creative Script Alignment object;
- no acknowledgement-only stall or request for `继续` occurs.

## W4-04 — Low-dependency combined gate is valid but not hidden

Clauses: `SEM-006`–`SEM-008`, `SEM-048`.

Context:

- a Compact single-screen or otherwise narrow project;
- rejecting the Core Script would not invalidate substantial downstream work.

Pass:

- High-Leverage Decision Record selects `Combined with Creative Script Alignment` and states why;
- the combined ECD-facing object first displays the complete Core Communication Script as a distinct section;
- page / state adaptation and exact copy appear after it;
- Core Script and adaptation approval scopes are separately identified;
- no separate gate is added merely for ceremony.

Fail:

- combined mode is used only to save a turn despite high downstream fan-out;
- Core Script is reduced to one sentence or hidden inside page copy;
- no separate authority scope is recorded.

## W4-05 — Existing authority-complete Core Script is reused

Clauses: `SEM-005`, `SEM-007`, `SEM-048`.

Context:

- ECD supplies an identifiable, current, aligned Core Communication Script.

Pass:

- Producer validates identity, version, authority, dependencies, and feedback;
- gate mode is `Existing Aligned`;
- script is reused without rewriting;
- Editorial Adaptation begins at the latest valid state;
- only stale or unresolved portions reopen.

## W4-06 — V3.1 active-project recovery

Context:

- Greenlight is valid;
- a V3.1 Creative Script with page architecture, Frame Scripts, and copy exists;
- no Core Script was separately visible or aligned;
- Visual has not begun.

Pass:

- valid Greenlight and Development evidence are preserved;
- actual progression is extracted into a Core Script candidate;
- High-Leverage test is applied;
- dependent page artifacts are marked provisional, not automatically destroyed;
- Core Script Alignment is requested;
- after approval, faithful downstream material is reused and only affected content is rebuilt.

Fail:

- Greenlight is requested again;
- all downstream work is discarded without comparison;
- provisional page work is treated as already authoritative.

## W4-07 — Discovery Signal produces independent Concept Reframing

Clauses: `SEM-011`–`SEM-017`, `SEM-047`, `SEM-049`.

Context:

- a high-engagement social post reveals an interesting public concept;
- the ECD asks for a new concept-sharing post using original examples, copy, and visuals;
- no source wording or assets will be used;
- no reproduction, tutorial, review, reliability, or commercial claim is commissioned.

Pass:

- source posture is `Discovery Signal`;
- engagement is used only for topic selection;
- Concept Reframing develops a distinct angle, Core Script, examples, copy, and visual approach;
- Research / Claims methods are omitted unless an actual factual dependency emerges;
- final public copy does not automatically mention the original creator, source link, inspiration, testing / non-testing status, concept-art status, infringement disclaimer, or future productization;
- the work stands without source identity and does not follow source wording, sequence, examples, or visual expression.

Fail:

- the post becomes a summary of the source;
- `灵感来源于`, `我们没有实测`, or similar language appears without a material reason;
- the discovery source becomes a visual composition or style mandate without reclassification.

## W4-08 — Factual Dependency receives narrow verification

Context:

- a Concept Reframing post depends on one specific current product or demonstration fact;
- the rest of the piece uses original examples and visuals.

Pass:

- source posture records `Factual Dependency` for the affected claim;
- only the factual unit needed by the publication is verified;
- no full reproduction or Product / Commercial Validation is required;
- source identity or attribution appears publicly only when material to accurate claim, direct evidence, rights, platform rule, or ECD instruction;
- other parts remain independent Concept Reframing.

Fail:

- one factual dependency forces the whole post into a tutorial or test report;
- no verification occurs despite a concrete current claim;
- source creator is inserted by default when not material.

## W4-09 — Direct-use material still activates rights controls

Context:

- the proposed post directly uses a screenshot, quotation, image, video frame, or recognisable protected expression.

Pass:

- source posture becomes `Direct-use Material`;
- Claims / Rights and Reference Contract controls activate;
- permission, transformation, attribution, and evidence-context requirements are recorded;
- unresolved material is replaced, narrowed, or blocked;
- Concept Reframing is not used to evade direct-use obligations.

## W4-10 — Future productization remains Deferred

Context:

- ECD says the concept may later become a sellable Skill;
- current commission is only an independent concept-sharing post and must not mention sales.

Pass:

- productization is recorded as a Deferred seed;
- current Evidence Obligation follows the current post, not the future offer;
- no commercial validation, sales preview, or product language appears in the current publication;
- a later productization commission creates a new or expanded Deliverable Contract and reassesses Evidence Obligation.

Fail:

- current post is over-validated or rewritten as a product teaser solely because future sales were mentioned.

## W4-11 — No defensive provenance language when no claim needs it

Context:

- original copy and visuals discuss a public concept without claiming testing, reproduction, documentary truth, source endorsement, or product reliability.

Pass:

- Copywriting does not add a disclaimer;
- Copy Editing removes unnecessary source / non-testing / concept language;
- Claims / Rights returns `public attribution required: no` and `public boundary language required: no` when no material condition exists;
- final copy reads as a direct independent concept-sharing post.

Fail:

- the publication conspicuously denies claims it never made;
- an internal provenance record is copied into the public caption.

## W4-12 — Source independence across editorial and visual work

Pass:

- Development records source-specific expression excluded;
- Core Script uses a distinct progression;
- Content Architecture does not copy the source sequence;
- Copywriting does not closely paraphrase the source;
- Visual does not copy source composition, characters, branded expression, or assets unless separately authorized;
- replacement test shows the final work has its own editorial and visual system.

Fail:

- only nouns, colors, or examples are changed while the source's structure and visual solution remain substantially intact.
