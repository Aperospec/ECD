# Visual Alignment and Anchor Regression

## Purpose

These tests verify that material visual systems are aligned through understandable, visible decision objects and representative anchors before broad production.

Apply:

- `../shared/ECD_DECISION_PRESENTATION.md`;
- `../art-director/references/ecd-friendly-visual-alignment.md`;
- `../art-director/references/anchor-keyframe-gate.md`;
- `../art-director/references/representative-design-comp.md`.

## Hard Failures

- Visual Direction Alignment is requested without analysis or low-cost visual evidence;
- the ECD is asked to choose professional jargon or prompt syntax;
- six or eight final-looking images are generated before anchors;
- a montage of unaligned images is called a representative proof;
- only a cover is proven for a multi-page world-led project;
- actual visual proofs are hidden in an attachment;
- Production activates before the Anchor Gate and Art Direction handoff;
- a rejected anchor triggers another blind batch.

## A01 — ECD-Friendly Visual Direction Proposal

Expected visible order:

1. What Art Director believes the ECD means;
2. visual evidence supporting the reading;
3. transferable reference principles;
4. prohibited transfer and likely wrong genre;
5. materially different routes;
6. Art Director recommendation and tradeoffs;
7. no more than a few plain-language questions;
8. next low-cost proof;
9. exact alignment scope;
10. hard stop.

The ECD must not need to open an attachment or understand terms such as spatial topology, focal hierarchy, lens language, or value grouping.

## A02 — Direction Alignment Does Not Authorize Batch

After ECD selects a Concept Route, expected next steps:

- formal studies;
- Storyboard;
- World / Cover Anchor;
- Representative Body Anchor;
- Design Comp when needed.

Prohibited:

- immediate full carousel production;
- six high-fidelity scene generations;
- Production Artist activation.

## A03 — World / Cover Anchor

Expected proof:

- the project-specific world is visible;
- governing metaphor is perceptible;
- whole-world / character hierarchy matches the selected route;
- reference principles are transformed;
- tourism, commercial theme-park, movie-poster, or game-key-art drift is controlled;
- copy territory is plausible.

## A04 — Representative Body Anchor

Expected proof:

- one specific Script beat exists inside the same world;
- environment remains conceptually active;
- character emotion does not erase world logic;
- scale, material, light, and route principles continue;
- frame does not become a generic cinematic vignette;
- page design remains possible.

## A05 — Third Anchor Constraint

A third pre-production high-fidelity anchor is allowed only when:

- a distinct page class cannot be inferred from the first two;
- the reason is recorded;
- it answers a new risk rather than offering a cosmetic variant.

## A06 — Representative Design Comp

When typography and layout are material, the Comp must use:

- accepted or credible anchor imagery;
- real copy;
- target geometry;
- actual line breaks;
- hierarchy;
- image–type relationship;
- mobile readability.

A prose description of intended typography is not enough.

## A07 — Primary-Conversation Visibility

Before Anchor / Design Alignment, the primary conversation must show:

- actual anchors / Comps;
- what each proves;
- how they belong to one system;
- reference principles used and source content rejected;
- remaining risk;
- proposed locks;
- open variables;
- decision request.

File-only proof fails.

## A08 — Compact Project

A two-screen project may combine:

- Storyboard;
- anchor;
- Design Comp.

Expected:

- both screens remain visible;
- the combined proof explicitly resolves image world and page design;
- no broad batch exists beyond the actual deliverable;
- intent / reference analysis is still performed when material.

## A09 — Valid Anchor Bypass

Input:

- narrow correction within an already accepted visual system.

Expected:

- bypass may be recorded;
- existing anchors and Design Comp remain authoritative;
- no unnecessary new direction ceremony.

Invalid bypass reasons:

- project is small;
- generation is fast;
- user already said “go ahead”;
- raw reference is attractive.

## A10 — Rejected Anchor

ECD says:

> The world is still too commercial and the people feel like movie characters.

Expected:

- preserve source feedback;
- diagnose whether failure begins in Visual Problem, Reference Reading, Concept Route, Storyboard, or Anchor;
- reopen earliest object;
- produce revised low-cost proof before new anchors;
- no multi-image rerender.

## A11 — Production Activation

Production may activate only when:

- Concept Route accepted;
- required Visual Direction Alignment resolved;
- Storyboard coherent;
- Anchor Gate passed;
- Design Comp passed when material;
- required Anchor / Design Alignment resolved;
- Art Direction Package Accepted for Handoff;
- Production inputs activated.

## Evaluation

Pass when visual decisions are:

- professionally analyzed;
- understandable to a non-specialist ECD;
- supported by representative visual evidence;
- narrow in decision scope;
- proven before batch production.
