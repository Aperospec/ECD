# Visual Metaphor and Concept Regression

## Purpose

These tests verify that Art Director transfers relational structure rather than copying source-domain objects, and develops materially different concept routes before Storyboard and anchors.

Apply:

- `../art-director/references/visual-metaphor-mapping.md`;
- `../art-director/references/visual-concept-development.md`;
- `../art-director/references/reference-reading-and-transfer.md`.

## Hard Failures

- visual metaphor is implemented as a literal object list;
- the project becomes an illustration of the source domain;
- only one route is developed when the system is unresolved;
- routes differ only by palette, weather, crop, or rendering style;
- one undifferentiated mood board replaces Mood, Style, Concept, and World Logic;
- a world-led concept becomes a set of isolated character vignettes;
- high rendering quality is used instead of formal studies;
- the easiest prompt is selected over the most faithful visual system.

## M01 — Life Archive / Life Amusement World Mapping

Target meaning:

- remembered life is fragmented, revisitable, interconnected, incomplete, and still growing;
- people own and enter their memories;
- AI remains a linking mechanism rather than external observer.

Source domain:

- an explorable amusement world.

Expected relational mappings include:

- memory episodes → distinct but connected regions;
- non-linear life → branching and looping routes;
- growth / difficulty → ascent, descent, threshold, and return;
- revisiting → lookout, return path, or rediscovery;
- loss / absence → restrained closed, quiet, interrupted, or missing regions;
- life continuing → unfinished territory;
- AI relationship → subtle indexing / linking logic.

Expected explicit literalization traps:

- one memory equals one ride;
- every page contains roller-coaster tracks;
- AI becomes park manager;
- loss becomes haunted-house imagery;
- future always becomes a construction crane;
- commercial attraction signage dominates.

## M02 — Relation-before-Object Test

Question:

> If recognizable rides, cable cars, shops, and attraction signs are removed, can the direction still feel navigable, layered, active, revisitable, and unfinished?

Expected:

- yes, through spatial and relational design;
- if no, metaphor remains superficial and must reopen.

## M03 — Three Materially Different Routes

Expected routes for the same project may include:

- Unified Life Mountain;
- Memory Infrastructure;
- Living Memory Landscape.

Each route must state:

- visual thesis;
- viewer relationship;
- world logic;
- subject–environment hierarchy;
- reference principles used and rejected;
- sequence potential;
- main benefit;
- main risk;
- likely wrong genre;
- low-cost proof.

Hard failure:

- Route A = sunset;
- Route B = rain;
- Route C = blue lighting.

## M04 — Board Separation

Expected:

- Mood Board answers emotional temperature;
- Style Board answers formal rendering language;
- Concept Board answers governing visual idea;
- World Logic Board answers system, regions, routes, rules, and continuity;
- Content / Asset Board contains only authorized material.

Hard failure: one collage silently determines all five.

## M05 — Formal Study Before Finish

After route selection, expected low-cost studies include the subset needed from:

- composition thumbnails;
- value studies;
- spatial / topology studies;
- scale studies;
- movement / line studies.

Expected behavior:

- solve large shapes and hierarchy before detail;
- identify why one study works;
- reject weak structures without polishing them.

## M06 — World-led vs Character-led Drift

Selected route:

- whole world is the primary subject;
- people demonstrate scale and use.

Failing output:

- repeated close emotional interactions;
- background park used only as atmosphere;
- each frame works as a standalone film still;
- world topology disappears.

Expected diagnosis:

- Concept Route / Storyboard failure, not merely Production detail;
- return to world / subject hierarchy;
- do not solve by changing clothing or weather.

## M07 — Color Script vs Repeated Grade

Failing sequence:

- every frame uses the same blue–orange sunset or rainy reflection;
- emotional and editorial states do not change.

Expected:

- reject cosmetic consistency;
- create sequence-level value, color, and light progression;
- preserve shared world while varying state according to the Script.

## M08 — Mixed Metaphor

Input Script uses archive, museum, amusement world, diary, map, and database interchangeably.

Expected:

- select one governing metaphor;
- define any supporting metaphor narrowly;
- remove terms or visuals that change the conceptual system;
- route Script-level semantic conflict upstream when necessary.

## Evaluation

Pass when the studio:

- preserves target-domain meaning;
- transfers relationships rather than decorative objects;
- develops real alternatives;
- separates board functions;
- solves large formal relationships before finish;
- keeps the selected world logic across the sequence.
